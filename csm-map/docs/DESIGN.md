# 디자인 규범 — CSM 거래처 지도 v0.3 "Field Atlas"

영업 현장에서 펼쳐 보는 **지도첩(atlas)** 한 장처럼. 크롬(패널·버튼·글자)은 종이와 잉크의 단색으로 물러서 있고,
**색은 오직 "어느 대리점의 것인가"라는 관계에만** 쓴다. 지도는 전국을 깔아 두지 않고, 고른 권역만 한 판(plate)으로 새로 찍어 낸다.

![개요](screenshots/overview.png)

## 1. 화면 구성

| 영역 | 역할 |
|---|---|
| 상단 바 | 레일 접기 · 이름/파일 · **권역 버튼**(지금 보는 권역 이름, ✕ 로 해제) · 통합 검색 · 상태 · 내보내기 · 테마 · 설정 |
| 왼쪽 레일 | 지금 권역 요약(거래처·대리점·시군구, 대리점 비중 띠) → 대리점 목록(색·이니셜·건수 막대) → 정정 필요 / 전체 표 |
| 무대(지도) | 판 + 맞닿은 시군구 맥락 + 점·거점·연결선 + 권역 밖 표시. 오른쪽 위 도구, 왼쪽 아래 범례, 오른쪽 상세 카드 |
| 오른쪽 시트 | 정정 필요 목록 / 전체 표(이 권역만 ↔ 전체). 지도 위로 미끄러져 나온다 |

읽는 순서: **권역(무엇을 보나) → 요약(얼마나) → 대리점(누가) → 지도(어디에)**.

## 2. 지도는 필터로부터 다시 그린다

- **판(plate)** = 고른 시군구(선택이 없으면 거래처가 있는 시군구). 흰 종이색 면 + 진한 테두리 + 아래로 떨어지는 그림자.
- **맥락** = 판과 경계를 맞댄 시군구만 따뜻한 회색 땅으로. 그 밖은 차가운 회청색 바탕(바다·여백). 맥락 시군구를 누르면 권역에 더해진다.
- 필터가 바뀌면 A/B 두 벌의 레이어를 번갈아 써서 **새 판이 살짝 떠오르며 교차 페이드**(480ms)하고, 판에 맞춰 날아간 뒤
  판 밖으로 멀리 못 나가게 이동·축소 범위를 잠근다. 같은 판이면 다시 그리지 않고 색만 바꾼다.
- 맞춤 여백은 범례 높이만큼 아래를 비워, 판이 범례에 가리지 않는다.

## 3. 색 — 관계만 말한다

### 3.1 대리점 10색 (`--h0 … --h9`)
dataviz 방법론으로 OKLCH 에서 뽑고 `validate_palette.js` 로 검증했다(명도대·채도 하한·정상 시각 전 쌍 ΔE ≥ 15, 라이트/다크 각각).
대리점이 26곳이라 색이 모자라므로 **"같이 보이는 대리점끼리만 달라 보이면 된다"** 로 문제를 바꿨다.

`csmmap/palette.py` — 충돌 그래프 색칠
- 충돌 가중치 = 같은 시군구에 함께 있는 거래처 수 + 맞닿은 시군구 공존(×0.35) + 거점 시군구 보정, 큰 대리점끼리는 살리언스 항 추가.
- 벌점 = 같은 색 1.6, 다른 색이면 정상 시각·색각 이상 ΔE 부족분의 제곱합.
- 큰 대리점부터 탐욕 배정 → 지역 개선 40회. 결정적(같은 데이터 → 같은 색).
- 결과: 상위 10개 대리점이 9가지 색을 쓰고, 같은 색끼리는 영업권이 거의 겹치지 않는다.

색각 이상 전 쌍 구분은 10색으로 불가능하므로 **보조 부호를 항상 함께** 쓴다: 이니셜 배지, 목록의 이름, 호버 시 나머지를 흐리게(고립), 연결선.

### 3.2 시군구 바탕
- **영업권**(기본): 그 시군구 1위 대리점 색을 땅색에 섞는다 — 1위 비중 50% 미만 16%, 이상 30%. 범례에 두 단계 견본.
- **거래처 밀도**: 순차 파랑 5단계(1 / 2–3 / 4–6 / 7–10 / 11+).
- **색 없음**: 점과 선만.

### 3.3 크롬 토큰 (`web/tokens.css`)
종이 `--paper/--surface*`, 잉크 `--ink … --ink-4`, 선 `--line*`, 지도 `--sea/--land/--land-ctx/--land-edge/--label*`.
상태색(`--fix`, `--ok`, `--err`)은 아이콘·글자와 함께만. 대비는 `tests/test_tokens.py` 가 라이트·다크 모두 검사한다
(글자 4.5:1, 선·면 3:1, 다크의 대리점 색은 밝은 테두리를 두르므로 바탕 대비 2:1 이상).

## 4. 기호

| 기호 | 뜻 |
|---|---|
| 채운 원(흰 테 + 얇은 외곽) | 거래처, 정확한 위치. 색 = 소속 대리점 |
| 점선 원 | 근사(검색 전, 시군구 중심 부근) |
| 점선 마름모(흐림) | 정정 필요 — 주소를 찾지 못해 시군구 중심 부근에 임시로 둠 |
| 가운데 흰 점 | 지도에서 직접 지정한 위치 |
| 큰 원 + 이니셜 + 건수 | 대리점 거점. 겹치면 서로 비켜 서고 **가는 지시선과 핀**으로 제자리를 가리킨다 |
| 흐린 작은 점 | 화면 안이지만 권역 밖인 거래처(맥락) |
| 가장자리 ▲ + 점/알약 | 화면 밖 권역 밖 거래처의 실제 방향. 가까운 것끼리 알약(색 견본 + 수)으로 묶고 범례·도구·카드를 비켜 선다 |

- 같은 자리에 겹친 점은 **해바라기 배열**(r = 6.4√(k+½), 137.5°)로 펼쳐 모두 보이게 한다. 줌마다 다시 계산.
- 시군구 이름표는 거래처가 많은 곳부터 자리를 잡고, 제자리 → 아래 → 위 → 오른쪽 → 왼쪽(가까운 자리 → 먼 자리) 순으로
  **다른 이름표·거점과 겹치지 않고 점을 가장 덜 가리는 자리**를 고른다. 자리가 없으면 숨긴다. 숫자는 이름 뒤 회색 고정폭.

## 5. 관계를 드러내는 상호작용

- **납품 연결선**: 거점 → 거래처 곡선이 평소 아주 옅게(20%) 깔려 관계의 결을 보여 준다. 권역 밖으로 가는 선은 평소 숨긴다.
- 대리점(목록 행·거점·거래처 점)에 올리면 그 대리점만 남고 나머지는 흐려지며, 선이 **그려지듯** 나타난다(거리순 지연 ≤ 260ms).
  권역 밖 거래처로 가는 선은 이때만 가장자리 표시까지 점선으로.
- 누르면 고정 + 상세 카드(이 권역/전체 거래처, 시군구별 막대, 평균 거리, 거래처 칩, "이 대리점 권역만 보기").
  고정한 대리점이 카드나 화면 밖에 가려 있으면 카드를 피해 보이도록 옮긴다(확대는 하지 않음).

## 6. 타이포

Pretendard(본문·제목, 400–700, 한글 부분집합) + IBM Plex Mono(수치·좌표·건수). 둘 다 `web/vendor/fonts` 에 내장 —
외부 글꼴 요청이 없고, 내보낸 단독 HTML 에는 data URI 로 들어간다. 크기 단계 `--t-2xs`(10.5) … `--t-2xl`(30).

## 7. 모션 — 상태 변화에만

| 상황 | 모션 |
|---|---|
| 첫 로드 | 레일 블록·범례·도구 순차 상승, 거래처 점 중심에서 바깥으로 스태거 스케일인(≤ 560ms), 수치 카운트업 |
| 필터 | 판 교차 페이드 + 떠오름, flyToBounds 0.85s |
| 대리점 강조 | 연결선 드로우, 거점 고리 확대, 고정 시 맥박 고리 |
| 겹친 점·거점 | translate 전환으로 미끄러지듯 재배치 |
| 시트·카드·팝오버·토스트 | 140–420ms 슬라이드/페이드 |

`prefers-reduced-motion: reduce` 에서는 모두 즉시.

## 8. 레이어 순서

무대(`.stage`)는 `isolation: isolate` 로 자체 쌓임 맥락을 갖는다 — Leaflet 창(z 400~700)이 바깥의 권역 팝오버·시트 위로 올라오지 않게.
무대 안: 맥락 300 · 판 340 · 경계선 360 · 이름표 450 · 연결선 560 · 점 600 · 권역 밖 표시 640 · 도구·범례 650 · 카드 660 · 툴팁 690.

## 9. 점검 루프 (Playwright, 매 회차)

`node check.js <url> <out>` 시나리오 17단계 — 부트, 레일 휠 스크롤, 대리점 호버·고정(카드 휠), 권역 팝오버 휠·체크,
판 다시 그리기, 맥락 호버, 정정 시트 휠, 표 휠·고정 머리행, 검색 결과 휠, 지도 휠 확대, 다크, 밀도, 레일 접기, 범례 펼치기, 권역 해제.
각 단계마다 "휠이 패널을 스크롤했는가 / 지도가 같이 확대됐는가"를 수치로 남기고 스크린샷을 눈으로 본다.
1440×900 과 1024×720 두 크기, 그리고 `--export-only` 단독 HTML 을 `file://` 로 열어 외부 요청 0건을 확인한다.

체크리스트
- [ ] 색은 대리점 관계에만 쓰였는가(크롬은 단색), 같이 보이는 대리점끼리 구분되는가
- [ ] 이름 없이 색만으로 식별해야 하는 곳이 없는가(이니셜·이름·고립 강조)
- [ ] 판이 범례·카드에 가리지 않는가, 이름표가 거점·다른 이름표와 겹치지 않는가
- [ ] 패널 위 휠은 패널만 스크롤하는가(지도 확대 없음)
- [ ] 라이트/다크 대비(pytest), 1024px 폭에서 줄바꿈·겹침 없음
- [ ] 모션은 상태 변화에만, 축소 설정 존중
