# 디자인 규범 — CSM 거래처 지도

참고: デジタル庁「ダッシュボードデザインの実践ガイドブック」(2026-03-31 정식판, 2026년도 굿디자인 베스트100)
<https://www.digital.go.jp/resources/dashboard-guidebook/> · 공식 테마 JSON <https://github.com/digital-go-jp/policy-dashboard-assets>

## 1. 정보 구조 — 전체 → 부분, 좌상 → 우하

| 영역 | 역할 | 위치 |
|---|---|---|
| 상단 바 | 제목 · 한 줄 요약(스크린리더 우선) · 검색 · 지오코딩 상태 · 전역 동작 | 1행 |
| KPI 스트립 | 전체 지표 4개 + 기준 시점. 권역 선택 시 비교 기준(전체 대비 %, 권역 밖 수) | 2행 |
| 필터 바 | 시도 세그먼트 → 시군구 칩(내림차순) → 적용 / 프리셋. **영향을 받는 지도는 바로 아래** | 3행 |
| 지도 | 전체 공간. 선택 권역 강조, 권역 밖은 가장자리 표시기 | 4행 좌 |
| 패널 | 부분·상세: 대리점 / 거래처 / 미해결 / 표 + 상세 카드 | 4행 우 |
| 정보 바 | 출처 · 갱신일 · 경계 버전 · 주석(근사/실패) · 정의 · 범례 | 5행 |

骨格(레이아웃·상태 흐름)을 먼저 고정한 뒤 表層(색·모션)을 입혔다.

## 2. 역할별 색 토큰 (`web/tokens.css`)

| 역할 | 라이트 | 다크 | 용도 |
|---|---|---|---|
| Text / Label | `#1a1a1c` / `#626264` | `#ececf1` / `#a9a9b3` | 본문 / 보조 |
| Background Standard / Highlight / Control | `#f8f8fb` / `#e8f1fe` / `#f2f2f2` | `#171a23` / `#1a2440` / `#20242f` | 카드 / 강조 카드 / 조작 UI |
| Chart Primary / Secondary | `#3460fb` / `#0017c1` | `#7096f8` / `#9db7ff` | 강조 대상(선택 대리점·선택 권역) |
| Chart Neutral | `#767676` `#999999` `#cccccc` | `#8a8e9a` … | 강조하지 않는 데이터 |
| Semantic Negative / Success / Warning | `#fe3939` / `#259d63` / `#ac3e00` | `#ff7171` / `#51b883` / `#ff8d44` | 실패 / 수동·완료 / 근사 |

규칙
- **색만으로 식별하지 않는다.** 대리점은 육각 배지+이니셜, 근사는 점선 중공 링, 수동은 중심점, 권역 밖은 방향 화살표.
- 기본은 **주목 모드**: 모든 점은 Neutral, 호버/고정한 대리점의 거래처만 Primary. 26색 '대리점별 색'은 옵션이며 이니셜을 유지한다.
- 대비: 텍스트 4.5:1, 그래프 색면 3:1 — `tests/test_tokens.py` 가 라이트·다크 양쪽을 검사한다.
- 장식 금지: 3D·과한 그림자 없음. 카드는 1px 경계 + radius 12, 패딩 12, 수직 간격 8.

## 3. 타이포

제목 20 / 소제목 14 / 본문 13 / 보조 12 / 미세 11 px. 숫자는 `tabular-nums`. 시스템 산세리프(Pretendard가 있으면 우선) → Noto Sans KR.

## 4. 지표·메타 정보

- KPI 는 값 + 비교 기준 + 기준 시점(xlsx 수정 시각). 증감은 Positive/Negative 색 + 기호.
- 정보 바: 출처(파일·시트·수정 시각), 지오코딩 출처, 경계 데이터 버전·출처, 주석(근사 N·실패 N·경고), 용어 정의 대화상자.
- 표 보기 탭 + CSV 다운로드로 원데이터를 공개한다.

## 5. 모션 — 상태 변화에만

| 상황 | 모션 |
|---|---|
| 데이터 로드 | 거래처 점 서→동 스태거 스케일인(≤560ms), 배지 스케일인, KPI 카운트업 |
| 권역 적용 | `flyToBounds` 0.9s, 폴리곤 채움 전환 520ms, 칩 스프링 |
| 대리점 호버/고정 | 거미줄 `stroke-dashoffset` 드로우인(거리순 지연 ≤260ms), 배지 펄스 링, 연결 점 1.5배 |
| 가장자리 표시기 | transform 전환으로 미끄러짐, 묶임 시 알약 폭 전환, 등장 스프링 |
| 패널·대화상자·토스트 | 160–280ms 페이드/슬라이드 |

`prefers-reduced-motion: reduce` 에서는 모두 즉시 전환.

## 6. 접근성

- 모든 마커·가장자리 표시기·칩·행은 키보드 포커스 가능(`tabindex`, `aria-label`). 포커스 시 툴팁 표시.
- 요약 한 줄은 `aria-live`. 상태 변화는 토스트(`role=status`).
- 라이트/다크 모두 대비 검사 통과. 색각 다양성: 형태 구분 + 이니셜.

## 7. 회차 점검 체크리스트 (스크린샷 루프마다)

- [ ] 좌상→우하로 읽히는가, 필터 아래에 영향 영역이 있는가
- [ ] 색 수 ≤ 5(주목 모드), 색 없이도 구분되는가(흑백 기준)
- [ ] 수치 텍스트 4.5:1, 색면 3:1 (pytest)
- [ ] 정렬 순서에 의미가 있는가(거래처 수 내림차순)
- [ ] 출처·시점·주석·정의가 보이는가
- [ ] 불필요한 장식·그리드·겹침이 없는가 (라벨 밀도, 툴바와 표시기 충돌)
- [ ] 모션이 상태 변화에만 쓰였는가, 축소 설정을 존중하는가
- [ ] 1100px·860px 폭에서 깨지지 않는가
