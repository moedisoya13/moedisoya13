# Slasher X Slasher — Game Design Document

> iPhone Safari 웹 게임 · **세로 화면** · 단일 HTML 파일
>
> **표기 규칙** — 각 항목의 `원안`은 기획자가 직접 정한 내용, `세부`는 대화 중 Claude가 제안하고 채택된 내용이다.
> 모든 수치는 **초기값**이며 플레이테스트로 튜닝한다 (→ [§10 튜닝 파라미터](#10-튜닝-파라미터)).

## 0. 핵심 컨셉

- **장르**: 탑뷰 slasher 추격 생존 + 코믹스 히어로 복수극
- **백미**: *아슬아슬한 추격전*. 모든 규칙은 "근소한 차이로 살아남는 긴장감"을 기준으로 판단한다.
- **한 판 흐름**: 살인마 1명 랜덤 선정 → 미로 저택에서 도망치며 월계관으로 **SHAZAM** 수집 → 망토 히어로로 변신해 역추격 → 처벌 시퀀스(리듬 입력)로 살인마 HP를 깎아 승리

```
[Tap to start]
     │
     ▼
[살인마 랜덤 선정] → 영화 타이틀 카드 → 귀엽게 변조된 비명
     │
     ▼
┌──────────── 추격전 (도망자) ────────────┐
│ 열쇠·문·은신처·변기·꿀병으로 생존        │◀───────────────┐
│ 월계관 → 슬롯 → S·H·A·Z·A·M / 꿀병      │                │
└──────────────┬──────────────────────────┘                │
               │ 6글자 완성                                 │
               ▼                                            │
      벼락 ⚡ → 망토 히어로 20초 (복수극, 역할 반전)        │
               │                                            │
     ┌─────────┴──────────┐                                 │
  20초 내 접촉        시간 초과 ── A 2개 상실, A 직접 수집 ──┤
     │                                                      │
     ▼                                                      │
 closeup → 처벌 시퀀스 (번개 3개 리듬 → 충전 펀치)           │
     │                                                      │
     ├─ 살인마 HP 0 ──▶ 승리                                │
     └─ 생존 ──────── A 2개 상실, A 직접 수집 ───────────────┘

패배: 플레이어 HP 0 / 마녀 양초 6개 / 박사 카운트다운 종료
```

## 1. 비주얼 & 연출

| 항목 | 원안 | 세부 |
|---|---|---|
| 그래픽 | 가벼운 극세 픽셀, 탑뷰 | 저해상도 내부 버퍼 → 정수 배율 업스케일 |
| 모션 | 페르시아의 왕자 수준으로 프레임을 세분화한 매우 부드러운 동작 | 그림 에셋 없이 **procedural 관절 애니메이션**을 저해상도 픽셀로 렌더 |
| 테마 | slasher 영화 | — |
| 시야 | 시야가 닿지 않는 영역은 그늘지듯 흐려짐. 기본 시야는 넓게 | 진행 방향 **손전등 cone**(9.5칸, 약 150°) + 몸 주변 3칸 원, 벽에 가려지면 어둡게 (LOS shadow casting) |
| 길 윤곽선 | 길의 윤곽선은 항상 보임 | 바닥과 벽의 경계를 1px 선으로 그려 안개 위에 얹는다(팩맨식). 잠긴 문은 빨간 막대로 표시 |
| 오프닝 | 살인마 이름이 영화 타이틀처럼 표시, 귀엽게 변조된 비명과 함께 추격 시작 | 비명은 Web Audio로 합성·pitch 조작 |
| 히어로 | 가슴에 **벼락 무늬**가 있는 근육 거한, 망토 | — |
| 처벌 시퀀스 | 단순화 없는 **극화체**, 입체감 있는 묘사 (다른 장르처럼) | 코드 렌더(굵은 잉크선·해칭·하프톤·집중선·입체 음영). 일러스트 PNG로 **교체 가능한 슬롯** 구조 |

> 코드 렌더 극화체는 "코믹스 극화 느낌"까지는 확실히 가능하지만 손그림 일러스트 수준의 해부학적 디테일에는 한계가 있다.
> 그래서 처벌 시퀀스 그림은 외부 이미지로 바꿔 끼울 수 있게 설계한다.

## 2. 맵

| 항목 | 원안 | 세부 |
|---|---|---|
| 구조 | 팩맨 스타일 **막다른 길이 없는** 미로 저택 | 매 판 **랜덤 생성** (braid maze + 방 배치) |
| 방 | 잠긴 방, **문 두 개짜리 통과형** | 방 벽·외벽은 파괴 불가 (도살자 예외 없음) |
| 카메라 | — | 플레이어 중심 스크롤 |
| 은신처 | 숨기 가능 | 옷장, 침대 밑 등. **문 안쪽 칸과 붙지 않게** 배치해 숨기와 문 열기·잠그기 버튼이 한 칸에서 겹치지 않는다 (변기도 같은 규칙, 변기와 은신처끼리도 서로 겹치지 않음) |
| 변기 | 변기끼리 빠르게 이동 | **한 쌍만** 등장, 들어간 쪽의 짝으로 나옴, 쿨다운 **2초**, **살인마도 사용 가능** |

## 3. 플레이어 (도망자)

| 항목 | 원안 | 세부 |
|---|---|---|
| HP | 3점, 공격 3점이면 사망 | 체력 회복 수단 없음 |
| 속도 | 살인마보다 **근소하게 빠름** | 플레이어 100 / 살인마 94 |
| 피격 | — | **무적 프레임 없음**. 대신 살인마 **공격 후딜레이 1~1.5초** + 플레이어 **넉백** (연속 피격 방지) |

### 조작 (iPhone)

| 위치 | 입력 | 기능 |
|---|---|---|
| 왼쪽 | **가상 조이스틱** (floating — 터치한 지점이 중심) | 이동. 레일 이동 보조: 교차로 ±0.46칸 안에서 미리/늦게 꺾을 수 있고 모서리는 대각선으로 깎아 돈다. ㄱ자 꺾임에서는 벽 쪽으로 밀고 있으면 통로를 따라 돈다. 대각선 입력(45°±8°)은 지금 가는 축을 유지해 교차로에서 지그재그하지 않는다 |
| 오른쪽 | **interaction 버튼** (상황별) | 숨기 · 문 해금/잠금 · 변기 · 양초 끄기 |
| 오른쪽 | 꿀병 버튼 (보유 시에만 표시) | 발밑에 꿀 트랩 설치 |

## 4. 시스템

### 4.1 열쇠 & 문

| 원안 | 세부 |
|---|---|
| 열쇠를 모아 잠긴 방을 열고 다시 잠금 | 열쇠 1개 = 잠긴 문 1회 해금(소모). 연 문을 다시 잠그는 건 무료 |
| — | 평소 살인마는 열쇠를 쓰지 않음 → 잠긴 문 앞에서 우회 or 파괴 |
| — | **잠긴 문 파괴**: 살인마가 **8초** 두드리면 부서짐 (camping 방지, "Here's Johnny" 연출) |
| 역할 반전 후 살인마도 열쇠 사용 가능, 단 문을 잠그지 못하고 숨지도 못함 | 복수극 중 살인마는 **맵에 떨어진 열쇠를 주워야** 해금 가능 → 열쇠 경쟁 |

### 4.2 숨기

| 원안 | 세부 |
|---|---|
| 은신처 옆에서 interaction 버튼으로 숨음 | — |
| 살인마가 옆에서 대기하며 **5초 로딩**(작은 원형 게이지) 후 확인하여 공격 | 숨는 장면을 봤거나, 마지막 목격 지점 근처 은신처를 확인 |
| 게이지가 차기 전에 빠져나가 도망치면 추격 재개 | — |

### 4.3 월계관 & 슬롯

| 원안 | 세부 |
|---|---|
| 빛나는 월계관이 랜덤 리스폰 | 맵에 동시 1~2개, 획득 후 몇 초 뒤 다른 위치에 리스폰 |
| 획득 시 상단 바 슬롯 회전 → 알파벳 또는 꿀병 | 확률 **알파벳 80 : 꿀병 20** |
| 알파벳 S · H · A · Z · A · M | A는 두 칸 — 세 번째 A부터 중복 |
| **중복 알파벳**: 수집되지 않음. 대신 5초간 **추격자 위치 표시** + **속도 소폭 증가** | (무적 효과는 삭제됨) |

### 4.4 꿀병

| 원안 | 세부 |
|---|---|
| 일회성 트랩, 적을 잠시 접착 | 최대 3개 보유, 버튼으로 발밑에 설치, 접착 시간 초기값 3초 |

### 4.5 Shazam 변신 & 복수극

| 원안 | 세부 |
|---|---|
| SHAZAM 6글자 완성 → 도망자에게 **벼락** → 동명의 히어로에서 영감 받은 **망토 히어로**로 **20초** 변신 | — |
| 복수극 시작, 플레이어가 추격자 역할 | 살인마 AI는 도망 모드로 전환 |
| 20초 안에 살인마에 닿으면 **closeup** → 처벌 시퀀스 | — |
| 첫 Shazam 이후 살인마 머리 위에 **하트 3칸** 상시 표시 | — |
| — | 히어로 속도 = **그 시점 살인마 속도 + 소폭** (살인마가 빨라져도 복수극이 아슬아슬하게 유지) |
| — | 복수극 중 살인마의 공격·능력이 히어로에게 맞으면 **데미지 없이 0.5초 경직** |
| — | 복수극 중 **시간 제한형 능력은 모두 정지** (마녀 양초, 박사 타이머, 초진화체 진화) |

**실패 (20초 초과)**

| 원안 | 세부 |
|---|---|
| 다시 도망자로 돌아가고 **A 두 개만** 잃음 (S·H·Z·M 유지) | — |
| 이후로는 월계관 대신 **A를 직접 수집** | A 아이템이 맵에 직접 스폰. 이 구간에는 월계관이 나오지 않음 (= 꿀병 획득 불가) |

### 4.6 처벌 시퀀스

| 원안 | 세부 |
|---|---|
| 화면 전환, 극화체 화면 | — |
| 좌측: 근육질 코믹스 히어로가 잡고 때릴 듯 손을 치켜듦 / 우측: 극화체 살인마 | 살인마별 묘사 포인트는 §6 참고 |
| 리듬 게임처럼 날아오는 **번개 마크 3개**를 타이밍 맞게 누르면 주먹에 전류가 **최대 3단계** 충전 | — |
| 판정 문자(Perfect 등) 없이 **이펙트만** | — |
| 살인마를 때려 생명점을 깎음, **최대 충전 시 일격에 승리** | 데미지 = 충전 단계 (0단계 = 헛스윙, 데미지 0) |
| — | 살인마 생존 시: 맵 복귀, 도망자로 전환, **A 두 개만 상실 → A 직접 수집** (실패와 동일 규칙) |
| — | 복귀 직후 살인마는 맵 반대편에서 **2~3초 기절** |

### 4.7 승패

| 결과 | 조건 |
|---|---|
| 승리 | 살인마 HP 0 |
| 패배 | 플레이어 HP 0 |
| 패배 | 마녀: 양초 6개 점등 |
| 패배 | 박사: 카운트다운 종료 |

## 6. 살인마 (6명)

### 6.1 도살자 — The Butcher

| 원안 | |
|---|---|
| 모티프 | 13일의 금요일 등 괴력 슬래셔 |
| 외형 | **사자 탈** |
| 무기 | 큰 **중식도**, 데미지 **2점** (사실상 2타 사망) |
| 능력 | **30초**에 한 번, 통로와 통로 사이 벽을 뚫어 길을 냄. 맞은편에 플레이어가 있었다면 **2초 기절** |
| 문 | 잠긴 문을 더 빨리 파괴 |

**세부**
- 벽 뚫기 전조 0.8초: 벽에 금이 가고 흔들리며 먼지 (플레이어 쪽에서도 보임)
- 뚫린 구멍은 **영구** — 판이 길어질수록 미로가 트임
- 통로 사이 벽만 가능 (방 벽·외벽 불가)
- AI 발동 조건: 플레이어까지 경로가 크게 짧아질 때
- 문 파괴 **4초**
- 복수극 중 벽 뚫기를 탈출용으로 사용
- 비명: 굵은 포효를 pitch-up한 새끼 사자 울음
- 처벌 묘사: 금 간 사자 탈 사이로 보이는 눈, 피 묻은 앞치마, 떨어진 중식도

### 6.2 마녀 — The Witch

| 원안 | |
|---|---|
| 모티프 | 오컬트 노파 |
| 무기 | 손톱 |
| 능력 | **20초**마다 생기는 양초를 설치, 시야를 밝힘 |
| 대응 | 플레이어는 interaction으로 양초를 끌 수 있으나, 끄면 위치가 잠시 노출 |
| 2개 점등 | 미묘하게 다른 **가짜 양초**가 무작위 설치. 가짜를 끄면 데미지 + 잠시 감속 |
| 4개 점등 | 플레이어 위에 **살피는 눈** 아이콘, 위치가 잠시 보임 |
| 6개 점등 | **육망성** → 플레이어가 바닥의 **지옥문**으로 빠지며 **즉시 패배** |

**세부**
- 설치: 마녀가 서 있는 자리, 설치 중 1초 정지
- 빛: 양초 주변은 플레이어 시야와 무관하게 밝음, fog 너머로 희미하게 보임. 빛 안의 플레이어는 멀리서도 마녀에게 보임
- 끄기: 0.5초 홀드, 끈 양초는 사라짐, 끈 뒤 **3초** 위치 노출
- HUD: 상단 **양초 6칸** 게이지
- 4개 이상인 동안: 10초마다 눈 아이콘 2초
- 가짜 양초: 2개 이상인 동안 주기적 생성(최대 3개), 6개 카운트 불포함, 끄면 **1점 + 3초 감속**. 구분 단서: **초록 불꽃**(진짜는 주황), **라벤더빛 회색 촛농 + 검은 촛농 자국**(진짜는 상아색), 일정한 박자로 깜빡임(진짜는 불규칙), 더 작고 차가운 빛(반경 1.5칸, 진짜는 2.6칸)
- 복수극 중 설치·타이머 정지, 켜진 양초 유지
- 비명: cackle을 pitch-up한 장난감 같은 낄낄
- 처벌 묘사: 주름 깊은 얼굴, 갈고리 손톱, 녹아내린 촛농

### 6.3 수위 — The Janitor

| 원안 | |
|---|---|
| 모티프 | 화이트 데이에서 영감, **사백안** 경비원 |
| 무기 | 테니스 라켓 |
| 능력 | 플레이어와 마주보았을 때 **손전등** (쿨다운 5초). 맞으면 시야의 흐린 부분이 아주 까매지고 열쇠 식별이 어려워짐 |
| 등급 | **C**로 시작. 플레이어가 **열쇠·변기·꿀병**을 사용하는 것을 목격할 때마다 상승 (꿀 설치는 플레이 피드백으로 추가) |
| B | 변기 금지 |
| A | 꿀 사용 금지 |
| S | **시야 공유** (플레이어도 수위의 시야를 봄), 데미지 **3점** |
| 위반 | 금지를 어기면 머리 위 **사이렌** 아이콘이 울리며 잠시 노출 |

**세부**
- 손전등 전조 0.3초 ("딸깍") — 벽 뒤로 꺾으면 회피
- 암전 지속 8초, 그동안 열쇠는 2칸 이내에서만 식별
- 목격 카운트: **열쇠로 문 해금 + 변기 사용 + 꿀 설치**. 문 잠그기는 제외 → 3회 목격 시 S
- 금지된 행동을 목격당하면 사이렌과 등급 상승이 함께 일어난다 (예: A등급에서 꿀 설치 → 사이렌 + S)
- 금지 위반 시 행동 자체는 성공, 목격 여부와 무관하게 사이렌 + 3초 노출
- 등급은 하락하지 않음
- 데미지: C~A 1점, S 3점(즉사). 라켓 피격 시 넉백 큼
- 머리 위 성적표 배지 C/B/A/S, 상승 시 도장 연출
- 복수극 중 등급 변동 정지
- 비명: 호루라기 + pitch-up 비명
- 처벌 묘사: 극단적 사백안, 경비 모자, 줄 끊긴 라켓

### 6.4 초진화체 — The Evolver

| 원안 | |
|---|---|
| 모티프 | 에이리언 등 고속 진화 크리쳐 |
| 외형 | 송곳니가 많고 입이 큰 **촉수 사마귀** |
| 알 | 대기 상태, 플레이어와 **첫 조우 시 부화**. 자동 부화 없음, **위치 비공개**. 1분 뒤까지 미조우면 **플레이어 옆으로 순간이동** |
| 유체 | **3초 대기 시 은신** |
| 성체 | 부화 후 **1분 30초**. 은신 상실. 짧은 거리 **낫 모양 촉수**로 먹이를 낚아챔 (쿨다운 30초) |
| 완성체 | 부화 후 **3분**. **30초**마다 속도 또는 촉수 거리 중 하나가 미세하게 개선. 속도가 플레이어를 넘어서면 **날개**가 펼쳐짐 |

**세부**
- 유체 은신: 완전 투명, 2칸 이내에서 아지랑이처럼 보임, 이동·공격 시 드러남
- 촉수: 사거리 3칸, 0.5초 전조(촉수 움찔), 적중 시 바로 앞까지 끌려온 뒤 공격 연결
- 완성체 속도 강화 +1.5/회 → 5회째 플레이어(100) 초과, 날개 전개
- 데미지: 전 단계 1점
- 복수극 중 진화·강화 타이머 정지
- 비명: 부화 순간 아기 울음 같은 끽끽
- 처벌 묘사: 잡힌 시점의 진화 단계 모습 (일러스트 3종)

### 6.5 박사 — The Doctor

| 원안 | |
|---|---|
| 모티프 | 미친 과학자 (릭 앤 모티에서 영감) |
| 카운트다운 | 머리 위 **5분** 카운트다운 아이콘. 완료 시 폭발과 함께 **플레이어 패배** |
| 본체 | 공격력 없음. 플레이어와 닿으면 **타이머 초기화** |
| 능력 | **60초**에 한 번, 랜덤 위치로 **텔레포트** 또는 **킬링 머신 소환** (개수 제한 없음 — 플레이 피드백으로 2체 제한 해제) |
| 킬링 머신 | **회전 톱날** 로봇, **드릴** 로봇. 박사와 일정 거리 유지(멀어지면 휴면), search & destroy |
| Shazam | 완성 시 모든 머신 소멸 |

**세부**
- 구도 반전: 플레이어가 박사를 쫓아 리셋, 그동안 머신이 플레이어를 쫓음. 평소 박사는 플레이어 회피 AI
- 접촉 시 타이머 리셋 후 비명과 함께 **즉시 랜덤 텔레포트** (60초 주기와 별개)
- **시야 공유** (플레이 피드백으로 추가): 박사와 모든 머신(휴면 중 포함) 중 누구든 플레이어를 보면, 깨어 있는 머신 전부가 그 위치로 추격한다
- 60초 행동은 무작위(소환 55% / 텔레포트 45%). 머신은 톱날·드릴이 같은 수가 되도록 번갈아 나온다
- 머신: 박사 8칸 초과 시 휴면, 데미지 1점. 톱날 = 0.5초 전조 회전 돌진, 드릴 = 잠긴 문 4초 파괴
- 복수극 중 타이머·텔레포트 정지, 처벌 시퀀스 후 타이머 5분 리셋
- 비명: 트림 섞인 "으억!" pitch-up
- 처벌 묘사: 흰 삐죽머리, 흘러내린 침, 깨진 플라스크

### 6.6 무사 — The Samurai

## 13. 살인마 모드 — HUNT

입장을 바꾼 모드. 플레이어가 살인마가 되어 AI 도망자들을 사냥한다. 타이틀에서 **RUN**(도망자 모드)과 **HUNT**(살인마 모드)를 고른다.

### 13.1 원안 (확정된 답변)

| 질문 | 결정 |
|---|---|
| 승리 조건 | **여러 명 사냥** — 동트기 전에 도망자 전원 처치 |
| AI의 SHAZAM | **없음** — 살인마 모드에는 월계관·슬롯·변신·복수극·처벌 시퀀스가 없다 |
| 살인마 선택 | **6명 중 직접 선택** — 초상화 카드 6장 중 하나를 고른다 |
| 도망자 체력 · 경기 시간 | **도망자마다 생명점 3점**, 경기는 **총 10분** (플레이 피드백으로 일격 처치·5분에서 변경) |
| 도망자 수 | **10명** (플레이 피드백으로 4명에서 변경) |

### 13.2 기본 규칙 (세부안)

- 도망자 **10명**(민지·준호·서연·도윤·하은·지호·수아·현우·예린·태민, 옷 색으로 구분)이 살인마에게서 먼 곳(경로 12칸 이상)에 흩어져 시작한다. 서로 8칸 이상 떨어뜨리고, 자리가 모자라면 6 → 4 → 2칸으로 간격을 줄인다.
- **10분** 뒤 동이 트면 종료. 남은 40초부터 화면이 서서히 밝아진다.
  - 전원 처치 → **PERFECT HUNT**
  - 시간 종료 → **DAWN**, 처치 수와 생존자 표시
- **생명점 3점.** 공격마다 살인마별 피해(13.5)를 입고, 0이 되면 쓰러진다. 시체는 그 자리에 남는다.
  - 맞으면 도망자 모드와 같은 **넉백(1.7칸 × 살인마 배율)**으로 밀려나고 곧장 달아난다.
  - 맞은 직후 **0.8초** 동안 깜빡이며 추가 피해를 받지 않는다(넉백이 막혀 연타당하는 것 방지).
  - 아드레날린: 맞으면 스태미나가 다시 찬다.
  - 회복 수단은 없다.
- 살인마의 속도는 도망자 모드와 같다(기준 속도 × 1.0).
- 시야는 도망자 모드와 같은 부채꼴 + 근거리 원형이다.
  - 시야 밖의 도망자는 보이지 않는다.
  - 진짜 양초 빛 안, 노출 상태, 무사의 투시 범위 안의 도망자는 붉은 실루엣으로 보인다.
- **사냥 본능:** 15초 동안 아무도 보지 못하면 12초마다 2.2초씩 가장 가까운 도망자 방향을 붉은 고리(화면 밖이면 가장자리 화살표)로 알려 준다.
- 가까이 갈수록 심장 소리가 빨라진다(가장 가까운 도망자 기준, 8칸 이내).

### 13.3 조작

| 버튼 | 위치 | 기능 |
|---|---|---|
| 조이스틱 | 화면 아무 곳 | 이동 (도망자 모드와 같은 레일 이동) |
| 공격 (빨강, 큰 버튼) | 오른쪽 아래 | 무기 휘두르기. 1.9칸 안의 도망자를 자동 조준한다. 선딜 0.12초, 판정 1.5칸·전방 ±75°. 헛치면 0.5초 경직. 휘두르는 동안 이동 속도 60% |
| 능력 (보라) | 공격 위 | 살인마 고유 능력. 쓸 수 없으면 회색, 쿨다운은 금색 테두리로 표시 |
| 상황 (금색) | 공격 왼쪽 | 근처에 대상이 있을 때만 나타난다: 은신처 수색 · 잠긴 문 부수기 · 변기 · 우물 |

공격과 능력 입력은 0.25~0.3초 버퍼에 저장된다. 휘두르는 중에 눌러도 끝나자마자 나간다. 키보드에서는 Space 공격, R 능력, C 상황 행동을 쓴다.

#### 상황 행동

- **수색:** 은신처 옆에서 5초 동안 서 있으면(작은 원형 게이지) 안에 숨은 도망자를 끌어내 한 대 친다(도망자 모드에서 살인마가 플레이어를 찾았을 때와 같음). 움직이면 취소된다.
- **문 부수기:** 도망자가 잠근 문을 몸으로 부순다. 걸리는 시간은 살인마별 문 부수기 시간을 따르며, 도살자가 더 빠르다.
- **변기:** 반대편 변기로 이동하며 소음을 낸다. 쿨다운은 2초다.

### 13.4 도망자 AI

| 상태 | 행동 |
|---|---|
| 배회 | 걷는 속도(70%)로 열쇠·꿀병·양초를 찾아다닌다. 살인마가 5칸 안에 있는 아이템은 피한다. 바로 옆의 양초는 끈다 |
| 발견 | 짧게 얼어붙은 뒤(0.35초) "!"와 비명. 이후 4초 동안은 다시 비명을 지르지 않는다 |
| 도주 | 살인마 속도의 **96%**로 달아난다(도망자 모드 살인마의 도주 경로 계획 재사용). 열쇠가 있으면 잠긴 문을 열고, 지나온 문을 뒤에서 잠근다. 변기를 쓰고, 살인마가 3.6칸 안이면 꿀병을 떨어뜨린다 |
| 스태미나 | 7초 넘게 달리면 3초 동안 지쳐서 80% 속도가 된다(머리 위 땀). 쉬면 회복된다 |
| 숨기 | 시야에서 벗어나면 5.5칸 안의 빈 은신처로 숨는다(생명점을 1점 잃을 때마다 찾는 범위 +1.5칸). 수색이 시작되면 55% 확률로 게이지 30~85% 사이에 튀어나와 달아난다(수색은 즉시 취소). 살인마가 멀어지면 9초 뒤, 늦어도 28초 뒤에 나온다 |
| 소리 | 배회 중에 문 부수는 소리나 변기 소리를 들으면 달아나기 시작한다 |

- 열쇠는 맵에 6개 유지된다. 도망자는 열쇠를 최대 3개, 꿀병을 1개까지 갖는다.
- 꿀병은 3개 유지된다. 도망자가 깔아 둔 꿀을 밟으면 살인마가 3초 동안 붙는다.

### 13.5 살인마별 규칙

| 살인마 | 무기 | 능력 버튼 | 지속 규칙 |
|---|---|---|---|
| 도살자 | 중식도 (**2점**, 넉백 ×1.2) | **벽 뚫기**: 바로 앞 벽을 부숴 지름길을 낸다. 반대편 1.3칸 안의 도망자는 2초 기절. 쿨다운 30초 | 문 부수기가 빠르다 |
| 마녀 | 손톱 (1점) | **양초 설치**: 발밑에 양초를 둔다. 재고는 최대 3개이고 20초마다 1개 충전 | 진짜 양초 빛(반경 2.6칸) 안의 도망자가 보인다. **2개** 켜지면 12초마다 가짜 양초가 생긴다. 도망자가 가짜 양초를 끄면 **1점 피해**를 입고(넉백 없음) 기절·노출된다. **4개**면 10초마다 눈이 떠 2초 동안 전원이 노출된다. **6개**면 육망성 의식: 무작위 도망자 1명이 생명점과 관계없이 지옥문에 빠지고 양초가 전부 사라진다. 도망자는 진짜 양초를 끄면 3초 노출된다 |
| 수위 | 테니스 라켓 (1점, S등급 **3점**, 넉백 ×1.6) | **손전등**: 앞쪽(6칸, ±35°) 도망자를 2.5초 눈멀게(기절 + 노출). 쿨다운 5초 | C급 시작. 도망자가 열쇠·변기·꿀병을 쓰는 모습을 **목격**할 때마다 등급이 오른다. **B부터 모든 도망자의 시야를 공유**하고 변기 금지, A부터 꿀 금지: 어기면 사이렌과 함께 3초 노출된다. S는 원안대로 **3점 피해**(한 방에 처치) |
| 초진화체 | 이빨·발톱 (1점) | **촉수**(성체부터): 앞쪽 일직선 3칸 안의 도망자를 눈앞으로 끌어와 한 대 친다(1점). 쿨다운 15초 | 유체로 시작. 3초 멈추면 은신해 1.5칸 밖에서는 도망자가 알아채지 못한다. 1분 30초에 성체, 3분에 완성체가 되며 은신은 사라진다. 완성체는 30초마다 속도나 촉수 거리가 조금 는다. 속도가 기준을 넘으면 날개가 펼쳐진다 |
| 박사 | 전기봉 | **기계 소환**: 톱날·드릴을 번갈아 개수 제한 없이, 쿨다운 15초 | 전기봉은 피해 없이 2.5초 기절시키고, **기절한 도망자를 치면 1점 피해**(넉백으로 기절이 풀린다). 기계는 박사 8칸 안에서만 움직이며 보이거나 노출된 도망자를 쫓아 닿으면 **1점 피해**(기계마다 1.2초 쿨다운). **박사는 모든 기계와 시야를 공유**한다: 기계마다 앞쪽 6칸 부채꼴이 박사 화면에 밝혀지고(휴면 중인 기계도 눈은 뜨고 있어 감시 카메라처럼 쓸 수 있다), 기계는 박사나 다른 기계에게 보이는 도망자도 쫓는다 톱날은 일직선 돌진도 한다 |
| 무사 | 창 (1점) | **창 찌르기**: 0.45초 조준 뒤 일직선 6칸을 벽·문을 무시하고 관통, 걸린 도망자 전원 **1점 피해**. 쿨다운 8초 | 6칸 안의 도망자는 벽 너머로도 보인다(투시). 상황 버튼으로 **우물 2개**를 판다(서로 8칸 이상). 다 판 뒤에는 자유롭게 오간다 |

### 13.6 화면

- **선택 화면:** 2×3 카드에 극화체 초상화가 들어간다. 처벌 시퀀스의 겁먹은 얼굴 대신 노려보는 눈과 웃는 입으로 다시 그렸다. 카드마다 이름, 능력, 한 줄 설명이 있다. 같은 카드를 다시 누르거나 아래 버튼을 누르면 시작한다. "‹ 모드"를 누르면 타이틀로 돌아간다.
- **인트로:** "TONIGHT, YOU ARE THE ○○○" 타이틀 카드, 그 살인마의 비명, "동트기 전까지 4명을 사냥하라".
- **HUD:**
  - 왼쪽 위: 도망자 10명의 얼굴과 그 아래 3칸짜리 생명점 막대. 처치하면 X 표시
  - 가운데 오른쪽: 남은 시간. 1분 남으면 주황, 30초 남으면 빨강으로 깜빡인다
  - 오른쪽: 살인마별 게이지
    - 마녀: 양초 재고와 켜진 수 /6
    - 수위: 등급
    - 초진화체: 진화 단계와 진행 막대
    - 박사: 기계 슬롯
    - 무사: 우물 슬롯
- **도망자 머리 위:** 보이는 도망자에게 생명점 3칸.
- **결과:** PERFECT HUNT(핏빛) 또는 DAWN(새벽빛). 도망자별로 처치 또는 생존(남은 생명점)을 두 줄 칸으로 표시하고, 탭하면 타이틀로 간다.
