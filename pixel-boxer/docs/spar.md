# 한 라운드 스파링 (`spar.html`)

시작을 누를 때마다 새 시드로 **약속 대련** 한 라운드를 짜서(모든 공방을 미리 정하고 실제 시합 엔진으로 리허설), 첫 다운까지 저절로 보여 주는 페이지입니다. 짜 놓은 공방 타임라인이 화면 구석에 뜹니다. 6차 기획 §8(약속 대련: 방향)과 게임 스케치의 "라운드마다 미리 만든 약속 대련"을 처음으로 만든 것입니다.

```sh
npm run serve                                   # http://127.0.0.1:8766/spar.html  (#s-48213: 그 대련)
node tools/spar.mjs --seed 7                    # 한 라운드: 타임라인, 다시 돌린 시합, KO, 점검
node tools/spar.mjs --seeds 1-200               # 요약: 길이, 공방 수, 지킨 약속, 다양성, 안 나오는 것과 까닭, 짜는 시간, 점검
node tools/artifact.mjs spar.html src/spar.mjs out.html   # 아티팩트 (빌드 표시 포함; --since <커밋>: 바뀐 파일만)
```

## 페이지

- 처음 화면: 링, 가드를 든 두 선수, 제목, 시작 버튼.
- **시작**: 새 시드 → 대본을 짬(워커에서; 워커가 없으면 화면을 그리면서 조금씩) → 다 짜이면 제 속도로 재생(짜는 동안 "대본을 짜는 중… 공방 7", 두 선수는 가드를 들고 서 있음; 느린 기기에서 8초가 넘으면 짜인 데까지 먼저 재생하고 나머지는 앞서 짬) → 첫 다운 → 결과("KO 0:46 · 파랑 5D · 훅": 화면의 등급은 L/D, 코드와 문서는 명/암)와 시작 · 다시 보기. 재생 중에 시작을 누르면 새 대련. 시드는 HUD에 작게("대련 #48213"), 주소에 `#s-48213`.
- HUD: 두 선수(코너 색과 등급: "빨강 · 5L"), 체력 막대와 숫자(시작 체력이 그대로 보임), 라운드 시계. 속도(1× / ½×), 소리(켤 때까지 꺼짐), 옷(맨몸 / 체육복 / 후드: `?wear=`의 옷, 이 브라우저에 기억하되 없어도 됨). 빌드 표시("빌드 7c4c057 · 11-24").
- 구석의 타임라인: 다섯 줄, 지금 싸우는 공방에 ▶, 끝난 것은 흐리게 결과와 함께, 앞으로 올 것도 보임. 누르면 전체 목록(앞으로 올 것은 "약속: …"으로 리허설 결과까지).
- 카메라: 게임의 카메라(둘 사이 선의 옆에서, 돌면 천천히 따라 돌고 가까우면 다가감)에 공방마다의 시점을 부드럽게 더함: 풋워크는 위에서, 바디는 낮게 옆에서, 공방은 조금 가깝게. 타임라인 구석에서 두 사람을 비켜 잡음. 컷은 다운의 리플레이뿐.
- 다운: 게임과 같은 순서(제 속도로 끝까지, 이펙트가 다 꺼진 뒤 가까운 카메라로 짧은 슬로 리플레이, `src/replay.mjs`). 이 페이지가 그것을 부르는 곳은 `src/spar/knock.mjs` 하나.
- 이펙트: 게임과 같게 그림: 타격(`render/blow.mjs`), 방어(막음 · 패리 · 빗나감 · 기막힌 수비: `render/guard.mjs`의 오늘의 기본, 기막힌 수비의 슬로는 게임처럼 없음), 쓰러진 몸이 닿을 때의 바닥 고리. 게임이 그리는 법을 바꾸면 `src/spar.mjs`의 `react`도 함께 바꿉니다(게임의 `src/main.mjs`와 같은 줄).

## 라운드를 짜는 법 (`src/spar/plan.mjs`, `src/spar/cards.mjs`)

- **두 선수**: 일곱 등급 가운데 하나씩(각 1/7). 등급이 주는 기술(`profile.mjs loadout`)에, 남은 칸은 그 등급이 여는 기술 가운데 시드의 주사위로 채움. 이기는 쪽도 주사위(등급이 높을수록 잘 이김: 등급 차 하나에 12%p, 15~85%). 두 사람 다 같은 체력으로 시작합니다: 이기는 쪽이 5등급이면 28~38, 한 등급 낮을 때마다 2.5씩 낮게(1등급이면 18~28). 약한 선수의 깨끗한 주먹은 체력을 덜 깎기 때문입니다.
- **공방의 목록은 카탈로그 그 자체**: `src/audit.mjs`의 `SCRIPTS`(카탈로그가 싸우는 모든 카드)를 읽어 카드마다 공방 하나로 만듭니다. 종류는 카드의 칸으로 정함: 상대가 던지고 내가 받는 카드(`against`)는 수비, 사다리의 주먹은 주먹, 콤비네이션, 과시형 트릭과 반칙, 도발, 기술(파도 · 시프트), 진입 · 이탈, 풋워크. 카드의 등급(`setup`)이 그 공방을 하는 선수의 등급이고, 카드가 주는 기술을 그 선수가 가지고 있어야 합니다. 빠지는 것: 체력이나 카운트를 손으로 정하는 카드(다운 · 휘청임), 몸의 수치를 바꾸는 카드, 몸통을 손으로 겨누는 카드(`bodyshots.mjs shot`), 스틱을 직접 움직이는 펜듈럼, 등급별로 다시 있는 기본 드릴.
- **새 기술이 들어오는 길**: 카탈로그 카드가 생기면(SCRIPTS에 들어가면) 그대로 들어옵니다. 손으로 쓴 표는 둘뿐입니다: 공방 종류마다의 몫(`SHARES`)과, 끝내기 단계에서 반격으로 끝낼 수 있는 트릭 이름(`elbow|collar|pawDown`). 새 종류의 카드(새 칸)가 생기면 `kindOf`에 그 칸을 한 줄 더해야 합니다.
- **문법**: 열기(풋워크, 잽, 가드: 3공방) → 가운데(콤비네이션 대 가드, 수비와 반격, 바디, 과시형, 기술, 들어가고 빠지기) → 끝내기(진 사람이 처음 쓰러지는 한 방). 누가 리드하는지는 두 등급과 이기는 쪽으로. 공방 사이는 그 카드의 거리까지 걸어가 잠깐 쉼(풋워크).
- **리허설**: 시합은 복사할 수 없습니다(선수의 몸과 주사위가 클로저: `structuredClone`이 거부). 그래서 뽑은 카드를 먼저 **따로 차린 시합**에서 시험합니다: 두 선수를 카드의 자리에 세우고(등급 · 기술 · 지금 체력과 숨 그대로) 카드대로 나오는지(슬립이 빗나가게 하는지, 가드가 막는지, 반격이 닿는지), 어느 타이밍에(프레임 단위로 맞춰야 하는 수비는 상대 주먹이 프로보다 얼마나 빨리 · 늦게 닿는지로 짐작한 곳에서부터 상대의 누름을 앞뒤로 옮겨 가며 찾고, 이웃한 세 프레임 이상 되는 것만, 그 가운데), 두 사람의 체력을 얼마나 깎는지, 누가 쓰러지는지를 봅니다. 맞는 것이 나오면 라운드의 실제 시합에 그 자리에서 이어 붙여(그 카드의 거리까지 걸어가 쉬고, 카드) 돌립니다. 거기서 시험과 다르게 나오면 처음부터 다시 돌려(같은 입력은 같은 시합) 다음 타이밍이나 다음 카드를 씁니다. 풋워크와 혼자 하는 도발은 시험하지 않습니다.
- **KO**: 체력은 처음에 한 번만 정하고(둘 다 같게, HUD에 보임), 공방은 시험에서 잰 피해로 고릅니다: 진 사람이 아직 잃어야 할 체력을 남은 공방 수로 나눈 만큼쯤(많아야 그 2.2배), 이긴 사람은 계속 더 강하게. 진 사람의 체력이 7 아래로 내려가면 끝내기: 시험에서 이긴 쪽의 힘 있는 한 방(45 N·s 이상, 잽이 아님)으로 쓰러뜨리는 카드를 먼저 쓰고, 맞히기만 하고 쓰러뜨리지 못하는 것은 아직 자리가 있으면 한 공방으로 둡니다. 공방 수가 다 찼는데도(18, 막히면 22까지) 체력이 많이 남았으면 간을 먼저 노립니다(리버 블로 70 N·s 이상은 체력과 상관없이 다운); 다른 주먹도 그를 더 다치게 하는 공방으로 둡니다. 그 다운이 라운드의 첫 다운이고 끝이며, 그 앞에 다운이 있는 공방은 버립니다.
- **물리 점검**: 다시 돌린 라운드에 `src/audit.mjs`의 `auditor`를 KO까지 걸어 봅니다(`tools/spar.mjs`). 리허설에서 자기 몸의 점검을 깨는 공방을 버리는 것(`SPAR.audit`, 도구의 `--refuse`)은 해 보았지만 비쌉니다(실패마다 처음부터 다시 돌리므로 한 라운드가 12초에서 560초로): 꺼 두었습니다.
- **결정적**: 시드의 주사위(`anim/stance.mjs dice`)와 시합의 주사위만 씁니다. 같은 시드는 같은 라운드(같은 입력, 같은 사건). 짜다가 막히면 같은 시드의 다음 주사위 줄로 다시(`plan.attempt`).

## 숫자

(`node tools/spar.mjs --seeds 1-200`)

시드 1~200, 이 컨테이너(다른 작업과 함께 써서 무거운 상태)의 node에서:

| | 최소 / 평균 / 최대 |
| --- | --- |
| KO까지 시합 시간 | 39.3 / 54.8 / 82.5초 |
| 공방 수 | 14 / 17.2 / 22 |
| 시작 체력(둘 다) | 22 / 30.9 / 38 |
| 짜는 시간 | 2.7 / 8.4 / 42초 (같은 시드의 둘째 주사위 줄로 다시 짠 라운드 20개 포함) |
| 처음부터 다시 돌린 횟수 | 0 / 1.1 / 10 |

- 약속: 3446 공방 모두 다시 돌린 시합에서 타임라인의 줄 그대로; KO 200/200이 약속한 공방의 약속한 한 방; 등급 · 로드아웃에 없는 동작 0. 실제 시합에서 처음 시도한 것 3669번 가운데 3446번이 그대로 나옴(94%), 나머지는 처음부터 다시 돌려 다음 것.
- 다양성: 200라운드가 모두 다른 공방 순서. 공방 종류 157가지 가운데 145가지가 나옴. 기술 여덟 가지 모두 나옴(풀백 258, 크로스암 473, 시프트 129, 파도 73, 셸 62, 숄더 롤 19, 블록 & 파이어 11, 다운패링 7). 콤비네이션은 카탈로그 카드가 있는 일곱 가지 모두(23~43번); 1-2-5-2 · 훅 언더 · 페이크 둘 · 더블 훅 · 위아래 · 1-S-5-2-3-2는 카탈로그에 카드가 없어서(앞손 어퍼와 페이크는 아직 엔진에 없음) 나오지 않음.
- 안 나오는 것: 제자리 풋워크(기본 풋워크 일곱 장, 리듬 바운스: 서서 쉬는 것은 공방 사이 휴식이 이미 함), 패리(980번 뽑혀 333번 시험에서 카드대로 나오지 않음), 뒷목 잡고 어퍼(189번 뽑혀 46번 시험 실패: 앞의 스트레이트 · 훅이 상대를 밀어 뒷목에 손이 닿지 않음), 1등급의 어퍼컷 · 뒷손 훅(1등급이 이기는 쪽이 드묾).
- 다운: 스트레이트 90(실신 15), 훅 49(실신 13), 뒷손 훅 22(실신 10), 어퍼컷 17(실신 3), 숏 어퍼 8, 숏 훅 3, 시프트 훅 11(리버 10).
- 물리 점검(KO까지, 200라운드): 두 사람 사이(카드 거리 밖에서의 접촉, 엔진의 알려진 한계) 글러브가 상대 몸에 3888프레임(165라운드), 두 몸이 겹침 512프레임(51라운드). 자기 몸: 위팔이 가동 범위를 넘게 돎 635프레임(101라운드), 넘어질 자리에 0.3초 넘게 서 있음 179프레임(57라운드), 자기 글러브가 다른 팔에 54(31), 머리에 18(13), 중력보다 빨리 떨어짐 18(17), 그 밖에 몇 프레임. 리허설에서 이것을 깨는 공방을 버리면 한 라운드가 수십 배 느려져 꺼 두었습니다.
- 브라우저(크로미움, 소프트웨어 GL, 같은 무거운 컨테이너): 워커로 한 라운드 7.8초(앞 세 공방 1.3초), CPU 4배 느리게 11.5초(3.3초). 워커 없이(`?worker=0`) CPU 4배 느리게는 훨씬 느림: 그래서 느린 기기에서는 8초가 지나면 짜인 데까지 먼저 재생합니다.
