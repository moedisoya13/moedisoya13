## 2. 일하는 규칙 (사용자가 정한 것; 모두 유효)

**말과 글**
- 답은 **한국어가 우선**(필요하면 영어를 섞음). 사용자가 2026-11-25에 다시 말함: "한글로 출력 바랍니다", "한글 우선 출력 규칙".
- 사람에게 보이는 글에서 남의 대명사는 they/them.
- 코드·문서·주석·커밋에 AI 모델 이름을 쓰지 않는다("구현 쪽 모델", "기획 쪽 모델"). 커밋 메시지 끝의 두 줄(Co-Authored-By, Claude-Session)은 그 세션의 지시를 따른다.
- 사용자의 이메일 등 개인 정보는 외부로 보내지 않는다.
- 등급은 7개: 1, 2, 3, 4명, 4암, 5명, 5암. 코드·문서는 명/암, **화면은 L/D**(4L/4D/5L/5D).

**결정과 기록**
- 사용자의 지시·결정·보고는 받는 즉시 `docs/pending.md`에 적고 커밋한다. 채팅으로 정해진 것도 적는다.
- 단계를 마칠 때마다 커밋·푸시한다. PR은 요청이 있을 때만.
- 지우는 일(아티팩트, 세션, 코드, 자료)은 사용자의 승인 뒤에만 한다(§7).
- 사용자의 결정이 필요한 것은 미결 카탈로그(§3)에 올리고, 답은 그 페이지의 "제출"이나 채팅으로 받는다. ★(권장)는 기본안일 뿐, 고르지 않은 것을 ★로 읽지 않는다.

**시험과 점검**
- audit 한도를 넓히지 않는다. 시험에 예외 목록·허용 목록을 넣지 않는다. 결과를 보고 돌릴 시드를 고르지 않는다. 사용자의 승인 없이 시험을 느슨하게 하거나 있는 단언을 뒤집지 않는다(굽기가 바뀌어 수·해시를 다시 재는 것은 느슨하게 하는 것이 아니다). 못 맞추면 수치로 보고한다.
- 게임이 그리는 법(`src/main.mjs`의 `react`)을 바꾸면 `src/spar.mjs`도 같이 바꾼다. 소리는 `audio.hear` 하나로 같이 쓴다.

**비용 (사용자 결정 2026-11-24: "알려진 한계를 받아들이고 빨리 합치며 노력도를 낮춥니다. 이 부분은 알아서 개선.")**
- 단계가 카드·시험·점검을 통과하면 남은 "기준보다 나쁜 경우"는 알려진 한계로 적고 합친다. 고침 라운드는 단계마다 많아야 한두 번. 따로의 점검은 사용자가 바랄 때만.
- 에이전트의 노력: 기계적인 일은 medium~high, 구현은 high. xhigh는 쓰지 않는다(사용자가 다시 바라기 전까지).
- 조정자(메인 세션)의 재실행과 화면 확인은 합치기 전에 한 번만(전체 시험 + 화면 한 장).
- 쓸기(시드·격자)는 좁게.
- 한 라운드 스파링을 개발하는 에이전트는 기획 쪽 모델도 허용(Agent 도구의 `model: 'fable'`), 노력은 high까지.
- 에이전트는 모델과 노력도를 지정해 **새로** 띄운다(메시지로 이어 시키면 그때의 메인 세션 모델·노력도로 돈다). 브리프는 파일로 넘긴다.

**일하는 방식 (이 세션에서 굳은 것)**
- 일마다 작업 폴더(`git worktree add --detach <scratchpad>/<name> HEAD`)에서 에이전트가 스테이지하지 않고 고친다 → 조정자가 `git add -N . && git diff --binary`로 받아 본 저장소에 `git apply --3way --index` → 전체 시험 한 번 → 커밋·푸시 → 게시 → `docs/handoff.md` §3과 `docs/pending.md` 갱신 → 사용자에게 한국어로 보고.
- 에이전틱 모션 구현(사용자 지시 2026-11-22): 소스(영상·이미지)나 기술 구현 요청이 오면 ① 기획(기획 쪽 모델, high: 소스 분석, 관절 순서·협응·등급별 차이·잴 것을 문서로, 접촉 시트는 `docs/ref/`) ② 구현(구현 쪽 모델, high) ③ 물리 점검(구현팀의 QC; 따로의 점검은 사용자가 바랄 때).
- 오토 배틀러다: 조작이 없다(게임 화면의 단추는 시험용). 새 기술은 선수 AI(`src/game/brain.mjs`, `ai.mjs`)가 로드아웃(`src/game/techniques.mjs`)에서 고른다.
- 카탈로그 배치: 한 행에 두 개, 390 px에서 가로 스크롤 없음.

## 9. 사라지는 것과 다시 만드는 법
