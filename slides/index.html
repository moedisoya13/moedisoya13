움직이는 그라데이션 배경

layered radial · Canvas 2D · reveal.js 플러그인
슬라이드를 넘겨 보세요 — 배경이 슬라이드마다 다른 구성으로 넘어갑니다.
배경은 본문에 자리를 내주도록 옅게 잡혀 있습니다 (intensity · wash).

붙이는 법

<link rel="stylesheet" href="assets/gradient-bg.css">
<script src="assets/gradient-bg.js"></script>

<script>
  Reveal.initialize({
    plugins: [RevealGradientBackground],
    gradientBackground: { speed: 1, count: 12 }
  });
</script>

파일 두 개를 덱에 복사하고 플러그인 배열에 넣으면 끝입니다. gradientBackground 는 전부 선택 항목입니다.

옵션

이름기본값하는 일
paletteCSS --gbg-1..8blob 에 쓸 색 목록
baseColorCSS --gbg-baseblob 아래 바닥색
count12겹쳐 깔 blob 개수
speed1드리프트 속도 배율
intensity0.35blob 알파 배율 — 올리면 색이 진해진다
wash0.35바닥색 베일 — 가운데를 더 밝게 눌러 준다
buffer140캔버스 짧은 변 px — 작을수록 뿌옇다
transitionMs1200슬라이드 전환 크로스페이드 길이
reseedOnSlidetrue끄면 덱 전체가 한 배경으로 고정

나머지 옵션(blend · grain · fps)은 README 참고.

팔레트 갈아 보기

팔레트는 CSS 변수라 --gbg-* 만 고쳐도 되고, 런타임에 setPalette() 로 바꿔도 됩니다.

어떻게 그리나

  • radial gradient 타원 12장을 겹쳐 깐다 — 중심은 성긴 격자에 하나씩 놓고 셀 안에서 흔들어 빈 구석을 없앤다.
  • 캔버스는 짧은 변 140px. CSS 가 화면 크기로 늘리고, 그 확대 보간이 곧 블러다.
  • 위치는 시간의 순수 함수(사인 2개 합) — 탭을 다시 열어도 튀지 않는다.
  • 전환은 blob 파라미터 보간. 색은 OkLab 에서 섞어야 중간색이 안 탁해진다.

시드는 슬라이드 인덱스에서 나온다 — 돌아와도 같은 슬라이드는 같은 배경이다.

덜 움직이게 / 인쇄

  • prefers-reduced-motion 이면 드리프트를 멈추고 정지 프레임만 남긴다.
  • 탭이 백그라운드거나 B 로 일시정지하면 렌더를 멈춘다.
