3색 팔레트 샘플

칩은 원색 그대로입니다. 배경에 깔린 같은 색이 왜 이렇게 옅은지는 다음 장에서.

교체는 세 줄

:root {
  /* 같은 색을 여러 번 적으면 그만큼 비율이 올라간다 */
  --gbg-palette:
    #E60012, #F7E26B, #3A7D2E, #F7E26B, #3A7D2E, #F7E26B,
    #E60012, #F7E26B, #3A7D2E, #F7E26B, #3A7D2E, #E60012;
  --gbg-base: #f6f4f1;
}
gradientBackground: { intensity: 0.3, wash: 0.45 }

JS 는 건드리지 않습니다. --gbg-1..8 을 낱개로 덮어쓰면 덮지 않은 슬롯에 기본 파스텔이 남아 3색이 6색이 되니, 목록을 받는 --gbg-palette 를 씁니다.

원색이 옅게 깔리는 이유

  • blob 알파에 intensity 0.3 을 곱합니다 — 0.42~0.80 이 0.13~0.24 로.
  • 그 위에 바닥색 베일 wash 0.45 를 덮습니다. 가운데가 가장 진해서 텍스트가 앉는 자리를 제일 많이 진정시킵니다.
  • 캔버스는 짧은 변 140px. CSS 확대 보간이 곧 블러라 경계가 녹습니다.

원색을 그대로 깔면 본문이 읽히지 않습니다. 이 세 가지가 강한 색을 발표 배경으로 쓸 수 있게 만드는 장치입니다.

더 진하게 / 더 옅게

설정쓰임
intensity: 0.3, wash: 0.45이 덱 — 원색이라 기본값보다 더 눌렀다
intensity: 0.35, wash: 0.35라이브러리 기본 — 파스텔 기준
intensity: 0.6, wash: 0.2색을 더 보여 주고 싶을 때
intensity: 1, wash: 0표지처럼 배경이 주인공일 때

blob 은 palette[i % 길이] 로 색을 받습니다. 목록에 같은 색을 여러 번 적으면 비율이 올라갑니다 — 이 덱은 12칸이 한 번씩 돌아 빨강 3 / 노랑 5 / 초록 4 입니다. 화면 픽셀로는 빨강 11% / 노랑 84% / 초록 6%, 균등 배분(4/4/4)일 때는 빨강이 38% 였습니다.
