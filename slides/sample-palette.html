크림 옐로우 배경

선언한 색은 공식 코드 셋뿐입니다. 화면을 덮은 우유빛은 새로 만든 색이 아니라 #F7E26B 가 지면색 위에 옅게 얹힌 결과이고, #3A7D2E 두 칸이 그 위에서 흐름을 만듭니다.

왜 원색을 그대로 안 깔았나

  • 중성 회색 지면 위에 노랑을 옅게 깔면 채도가 먼저 빠져 올리브빛 회색이 됩니다. 지면색부터 우유빛으로 바꿉니다.
  • 밝기 단계를 만들려고 새 색을 선언할 필요가 없습니다 — 알파와 베일이 그 일을 합니다.
  • 단색이면 움직임이 눈에 안 잡힙니다. 명도차가 없으면 흐름을 볼 단서가 없어서, 초록 두 칸을 섞었습니다.

색을 진하게 쓰면서 더 잘 읽힙니다

변화 수치는 슬라이드 0 과 2 의 픽셀 차입니다. 초록 두 칸이 변화를 3.6 배로 키우면서도 본문 대비는 11:1 대를 지킵니다.

설정

:root {
  --gbg-palette:            /* 노랑 10 · 초록 2 — 둘 다 공식 코드 */
    #F7E26B, #F7E26B, #F7E26B, #3A7D2E, #F7E26B, #F7E26B,
    #F7E26B, #F7E26B, #3A7D2E, #F7E26B, #F7E26B, #F7E26B;
  --gbg-base: #FBF6E9;      /* 지면색 — 브랜드 색 아님 */
}
gradientBackground: { intensity: 0.55, wash: 0.3 }

움직임을 더 키우려면 초록 칸을 늘립니다. 셋까지는 우유빛이 버티고, 넷부터는 올리브로 넘어갑니다. 톤은 intensity 0.7 / wash 0.2(진하게) · 0.4 / 0.35(차분하게). 어느 쪽이든 색은 공식 코드 그대로입니다.
