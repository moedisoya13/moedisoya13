# ARROW INDEX — 신화 서바이벌 · 경험치 증시

iPhone 세로 화면에서 혼자 즐기려고 만든 가벼운 웹 게임. 뱀파이어 서바이버즈 계열이고 주인공은 궁수다.
월드는 1비트 흑백 픽셀, 색은 오직 **EXP 주가**(빨강 상승 / 파랑 하락, 한국 증시 관례)에만 쓴다.
배경은 일부러 비웠다 — 검정 바탕에 이동감만 주는 희미한 점뿐이라 몬스터·화살·탄이 묻히지 않는다.

- 플레이 파일: [`dist/index.html`](dist/index.html) — 외부 리소스 없는 단일 HTML (폰트까지 인라인, 약 210KB)
- `dist/arrow-index.html` — 같은 내용에서 `<!doctype>/<html>` 래퍼만 뺀 버전 (Claude 아티팩트 게시용)

## 규칙

| 요소 | 내용 |
|---|---|
| 이동 | 화면 아무 데나 끌면 그 자리에 조이스틱이 생긴다. 강궁은 가장 가까운 적을 자동으로 겨눠 한 발씩 쏜다 |
| 주가 바 | 얇은 바에 매초 1틱씩 움직이는 EXP 시세. 조이스틱 손가락이 화면 아래쪽에 있으면 위로, 위쪽에 있으면 아래로 비켜난다 |
| 매수 (좌상단) | **누르고 있는 동안** 시세가 멈추고, 그 사이 주운 EXP 는 경험치 바 대신 그 가격의 주식이 된다 |
| 매도 (우상단) | 누르는 즉시 보유 주식 전부를 현재가로 판다. 받는 EXP = 투입 EXP × (현재가 / 평단) |
| 스테이지 | 5분마다 바뀌어 30:00 까지 6개 (초원 → 명계 → 사막 → 설원 → 신전 → 혼돈). 매 스테이지 4:00 에 신화 보스 |
| 기록 | 생존 시간 → 처치 수 순으로 상위 10개를 이 기기 브라우저(localStorage)에 저장 |

시세는 평균 회귀 + 국면(강세/약세/횡보/급변) + 가끔의 급등락으로 만든다. 스테이지가 오를수록 변동성이 커진다.
시장 패시브: 배당(보유 수량 증식) · 레버리지(손익 배율 확대) · 손절선(매도 배율 하한) · 내부자 정보(다음 틱 미리 보기).

몬스터는 여러 신화에서 빌려 와 무작위로 섞어 낸다 — 스파르토이·하피·키클롭스·히드라(그리스), 드라우그르·와르그(북유럽),
스카라브·미라(이집트), 갓파·텐구·오니(일본), 도깨비·도깨비불·처녀귀신(한국), 강시(중국), 구울(아라비아).
보스 6종(메두사·미노타우로스·펜리르·아누비스·구미호·케찰코아틀)은 판마다 순서가 섞인다.

## 타격감 / 모션 장치

- 피격: 흰 섬광 + 스쿼시 스프링 + 넉백 + 불꽃 + 작은 충격 링 + 데미지 숫자, 치명타는 화면 흔들림
- 처치: 스프라이트의 **실제 픽셀이 튀어 흩어지고** 바닥에 튕긴다. 정예·대형은 히트스톱, 보스는 슬로모션 + 화면 반전
- 이동: 속도·카메라는 지수 감쇠로 보간, 카메라는 진행 방향을 살짝 앞서 본다. 좌표는 아트 픽셀이 아니라 기기 픽셀 단위로 찍어 1비트인데도 부드럽다
- 강궁(한 발 한 발): 0.27초 만작 → 화살촉 번쩍임 → 발사. 몸이 뒤로 밀리고 카메라가 반대로 튀며, 공기를 가르는 선과 긴 잔상을 남긴다.
  맞은 적은 크게 찌그러지며 멀리 밀려나고, 파편이 화살 방향으로 뿜어지며, 매 명중마다 아주 짧게 멈칫한다(연달아 멈추지 않게 120ms 간격).
  연속 사격 업그레이드도 매 발 시위를 다시 당긴다
- 보석: 빨려 들기 직전 살짝 튕겨 나갔다가 가속해 들어오고, 연속 획득 시 음이 올라간다
- 매수 중 주운 EXP 는 붉은 입자로 매수 버튼에, 매도 대금은 입자 줄기로 경험치 바에 날아간다

## 개발

```bash
node tools/build.mjs          # src/*.js + src/shell.html → dist/ (폰트 서브셋 인라인)
node tools/smoke.mjs <dir>    # iPhone 14 에뮬레이션으로 시작·이동·매수·매도 스크린샷
node tools/touch.mjs <dir>    # 조이스틱 + 매수 동시 터치, 매도, 레벨업 화면
node tools/botrun.mjs <dir> 10 240 0          # 자동 플레이(?bot) 10배속으로 밸런스 로그
node tools/botrun.mjs <dir> 10 240 0 '&t=1200' # 20:00 으로 워프해 후반 점검
node tools/bossshots.mjs <dir> medusa,fenrir   # 보스 화면 캡처 (?boss= 강제)
node tools/perf.mjs 1500      # 후반 장면 프레임 비용
```

빌드에는 Python `fonttools`+`brotli` 와 Galmuri 원본(`npm` 의 `galmuri@2.40.3` → `dist/Galmuri11.ttf`, `Galmuri11-Bold.ttf`)을
`tools/fonts/` 에 두어야 한다. 원본 TTF 는 저장소에 넣지 않는다.

디버그 쿼리: `?bot` 자동 플레이 · `&speed=N` 배속 · `&t=초` 시간 워프 · `&boss=이름` 첫 보스 지정.
키보드: WASD/화살표 이동, Space(누르고 있기) 매수, K/Enter 매도, P/Esc 일시정지, 1~3 카드 선택.

| 파일 | 역할 |
|---|---|
| `src/core.js` | 수학·보간·스프링·공간 해시·저장소 |
| `src/art.js`, `src/data.js` | 픽셀 아트 문자열, 몬스터/보스/무기/패시브/스테이지 수치 |
| `src/gfx.js` | 스프라이트 래스터화(외곽선·섬광·반전·디더 변형), 회전 화살/활 생성, Bayer 디더 패턴 |
| `src/market.js` | 시세 모델과 매수·매도 |
| `src/game.js`, `src/weapons.js`, `src/bosses.js` | 시뮬레이션, 무기 8종, 보스 패턴 |
| `src/render.js`, `src/hud.js`, `src/ui.js` | 월드 렌더링, 캔버스 HUD, DOM 오버레이 |
| `src/input.js`, `src/audio.js`, `src/main.js` | 터치/키보드, 합성 효과음, 루프와 자동 플레이 봇 |
