# 여명 전야 — 그래픽 기준 (초안 1: 로우폴리 극화)

> 채택: ①+⑤ 혼합 A안 `styles/9a-comic-lowpoly-3d.png` (Figma 노드 10:2). 원안 8종과 B안은 참고용으로만 둔다.
> 용사 디자인은 `before-dawn-hero-design.md`(돌아온 노용사)를 따른다. A안의 용사는 회색 머리, 남색 판금, 금 목가리개, 흰 망토, 주황 날의 직검으로 그 설정과 맞는다.

## 1. 한 줄 기준

**밤의 도시 위에 떠 있는 마천루 한 층을 잘라 낸 로우폴리 디오라마를, 미국 코믹스 표지처럼 먹선과 단색으로 칠한다.**

## 2. 화면 구성

- **카메라**: 고정 아이소메트릭 3/4 시점, 위에서 비스듬히 내려다본다. 회전하지 않는다.
- **무대**: 층 하나를 잘라 낸 판. 앞쪽 두 벽은 없고 뒤쪽 두 벽만 세운다. 판 바깥은 어두운 밤하늘과 먼 도시 불빛이다.
- **바닥**: 층의 우세 적 유형을 나타내는 단색 하나로 칠한다. 화면에서 가장 넓은 면적이고 층 정보를 전한다.
- **크기**: A안은 용사가 화면 높이의 약 1/4로 커서 빽빽하다. 실제 게임에서는 B안처럼 카메라를 물려 **방 하나가 화면에 다 들어오게** 하고, 용사는 화면 높이의 1/8 안팎(864p 기준 약 100px)으로 둔다.
- **소품**: 책상, 모니터, 엘리베이터 문 같은 도시 소품은 벽을 따라 둔다. 바닥 가운데는 비워 전투가 읽히게 한다.

## 3. 렌더 규칙

| 항목 | 규칙 |
|---|---|
| 형태 | 배경과 소품은 면이 보이는 로우폴리. 마왕성의 침식은 검은 가시와 보라 크리스털로 표현한다 |
| 명암 | 면마다 2단: 밝은 색 한 단과 먹 그림자 한 단. 그라데이션과 사실적 조명은 쓰지 않는다 |
| 외곽선 | 모든 모델에 굵고 고르지 않은 먹 외곽선 |
| 망점 | 그림자 면에만 옅게 |
| 잉크 튐 | 타격 지점에 큰 먹 튀김이 터지고, 바닥에 자국으로 남는다 |
| 의성어 | 손글씨 레터링(SLASH! 등). 큰 타격에만 띄운다 |
| 인물 단순화 | 컨셉 원화는 디테일을 그대로 두고, 게임 속 인물만 큰 판·관절 띠·3단 색으로 단순화한다. 용사의 규칙은 `before-dawn-hero-design.md` §5-1 |

## 4. 색 규칙

| 역할 | 색 | 규칙 |
|---|---|---|
| 먹 | `#0a0a0c` | 외곽선, 그림자, 잉크 튐 |
| 밤 배경 | `#0b0f1c` 안팎 | 판 바깥. 먼 도시 불빛은 작은 노랑·주황 점 |
| 층 바닥: 마물 | `#f2c230` | |
| 층 바닥: 언데드 | `#4fa94d` | A안 바닥 실측 `#3f9547`와 가깝다 |
| 층 바닥: 마법 | `#5c4d8e` | 용사의 남색과 가까워서 먹 외곽선과 흰 망토가 형태를 받친다 |
| 층 바닥: 중갑 | `#e0392f` | |
| 용사의 공격 | 주황 `#ff9a3c` | **용사 전용.** 칼날 테두리, 베기 궤적에만 쓴다. 적의 효과에는 쓰지 않는다 |
| 적의 공격 예고 | 빨강 빗금과 먹 테두리 | 중갑 층(빨강 바닥)에서는 흰 빗금으로 바꾼다 |
| 마왕성 침식 | 보라 크리스털, 검은 가시 | 벽과 판 가장자리에만 둔다 |

**적과 바닥이 섞이지 않게 한다.** 적의 몸 색은 그 적이 우세하게 나오는 층의 바닥색과 색상이 겹치면 안 된다. 예를 들어 언데드 층의 구울은 초록 피부가 아니라 A안처럼 잿빛으로 칠한다.

## 5. HUD (A안 기준)

- **왼쪽 위**: 용사 초상, 비스듬한 HP 막대, 성수 병 아이콘
- **오른쪽 위**: 비스듬한 상자 안의 시계(18:00→06:00), 팔각형 미니맵
- **아래 가운데**: 코등이 모양 금테 안의 카드 슬롯 3칸. 퀘스트 진행도와 콤보 스택은 슬롯 모서리의 작은 숫자로 표시한다
- HUD도 먹 외곽선과 평평한 색으로 그린다. 바닥색과 상관없이 읽히도록 칸 바탕은 먹색으로 한다

## 6. Godot 구현 메모

- **배경**: 3D 로우폴리 모델로 만들고 면을 평평하게 셰이딩한다. 직접 모델링하거나, 블록을 이어 붙이는 Godot 기능(GridMap, CSG)으로 조립한다.
- **2단 명암**: 빛의 양을 두 단계로만 끊는 툰 셰이더 하나.
- **먹 외곽선**: 모델을 살짝 부풀려 뒷면을 검게 칠하는 방법, 또는 화면 단위 외곽선 셰이더.
- **망점과 잉크 튐**: 그림자 면에 망점 셰이더를 씌우고, 잉크 튐은 바닥에 붙이는 데칼과 파티클로 만든다.
- **기존 보정 스크립트**: 생성한 2D 인물 그림의 잉크 잡티 정리와 배경 분리에는 `hero/clean/clean.py`를 그대로 쓸 수 있다.

## 7. 피할 것

- 그라데이션, 사실적인 빛 번짐, 과한 발광 효과
- 바닥 가운데의 잡동사니(종이, 의자)
- 적의 효과에 주황 사용
- 바닥과 같은 색상의 적
- 참고 표지 캐릭터의 상징(날개 투구, 번개 문양)

## 8. 인터뷰 페이지에 넣을 결정

| 결정 | 선택지 | 제 추천 |
|---|---|---|
| 인물 제작 방식 | ① 2D 극화 그림을 3D 공간에 세움 (Sprite3D) ② 인물도 3D 로우폴리 모델 | ①. A안의 인물은 실제로 손그림 극화에 가깝고, 주말 범위에서 리깅을 피할 수 있다 |
| 카메라 거리 | A안처럼 가깝게 / B안처럼 방 전체 | 방 전체 |
| 잉크 자국 | 바닥에 계속 남음 / 몇 초 뒤 사라짐 | 남음. 싸운 흔적이 층마다 쌓인다 |
| 의성어 빈도 | 모든 타격 / 처치·큰 타격만 | 처치·큰 타격만 |
| 망점 세기 | 없음 / 그림자에만 옅게 / 강하게 | 그림자에만 옅게 |
| 밤 배경의 시간 흐름 | 고정 / 06:00에 가까울수록 지평선이 밝아짐 | 밝아짐. 남은 시간이 화면에 보인다 |
