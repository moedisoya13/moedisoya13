# 그림 에셋

`sprites.json`에 파일 경로와 픽셀 크기가 있다. 전부 배경이 투명한 WebP이고, 그림은 테두리까지 잘려 있다(여백 없음). 기준점은 **아래 가운데(발)** 로 잡는다. 모든 그림은 오른쪽을 보며, 왼쪽은 좌우 반전한다.

원본 해상도는 화면 표시 크기의 약 2배다(고해상도 화면용). 화면에서 용사는 화면 높이의 1/8 안팎으로 그린다. 적의 상대 크기는 아래 높이 비율을 따른다.

| id | 설명 | 높이(px) | 비고 |
|---|---|---|---|
| hero_front | 용사 앞 대기 (화면 아래쪽을 봄) | 256 | 용사 6포즈는 같은 배율 |
| hero_back | 용사 뒤 대기 (화면 위쪽을 봄) | 254 | |
| hero_side | 용사 옆 대기 | 257 | |
| hero_slash | 용사 베기 | 196 | 주황 궤적이 그림에 들어 있다. 카드가 궤적을 바꾸므로 전투 중 궤적은 코드로 그리고, 이 그림은 타이틀·연출용으로 쓰는 편이 낫다 |
| hero_dash | 용사 어깨 돌진 | 214 | |
| hero_hurt | 용사 피격 | 234 | |
| slime | 슬라임 (마물), 자홍색 | 130 | |
| goblin | 고블린 (마물), 청록 피부 | 170 | |
| skeleton_archer | 해골 궁수 (언데드), 뼈 흰색 | 210 | |
| ghoul | 구울 (언데드), 잿빛 | 200 | |
| mage | 마도사 (마법), 진홍 로브에 청록 구슬 | 220 | |
| dark_knight | 암흑기사 (중갑), 검은 강철에 방패 | 260 | |
| demon_king | 마왕 (보스) | 420 | |

적 그림에는 주황이 없다. 주황은 용사의 칼 전용이다.
