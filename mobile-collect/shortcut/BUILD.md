# iOS 단축어 만들기 (최초 1회, 약 10분)

> **왜 완성된 단축어 파일을 주지 않나요?**
> iOS는 공유받은 단축어에 서명을 요구합니다. 서명은 Apple의 iCloud 링크로만 생기고
> 이 저장소에서는 만들 수 없습니다. 그래서 **액션을 직접 조립**합니다.
> 대신 판단 로직은 전부 `run-javascript-body.js` 한 덩어리에 들어 있어서,
> 조립하는 액션은 "받아서 → 분기해서 → 저장"뿐입니다.

> **액션 이름은 iOS 버전·언어에 따라 조금씩 다릅니다.** 아래 괄호 안 영문명으로 검색하거나,
> 설명된 *기능*으로 찾으세요. `웹페이지에서 JavaScript 실행`이 아예 안 보이면
> **설정 > 단축어 > 고급**에서 스크립트 관련 항목을 켜세요.

---

## 0. 준비

- iCloud Drive에 `coupang-price/manual/` 폴더를 만들어 둡니다. (파일 앱 > iCloud Drive)
- PC에 **Windows용 iCloud**가 설치돼 있으면 이 폴더가 PC로 자동 동기화됩니다.
  없으면 README의 "대안 전송" 절을 보세요. 단축어 조립은 동일합니다.

## 1. 새 단축어 만들기

1. 단축어 앱 > 우상단 **+**
2. 우상단 **정보(ⓘ)** 또는 단축어 세부사항
   - **공유 시트에 표시** 켜기
   - 입력 유형에서 **Safari 웹페이지**만 남기고 나머지는 끄기
3. 이름: `쿠팡 수집`

## 2. 액션 조립

### ① 웹페이지에서 JavaScript 실행 (Run JavaScript on Webpage)

- `run-javascript-body.js` **전체**를 붙여넣습니다.
  (폰에서 GitHub raw 화면을 열어 전체 선택·복사하는 게 가장 쉽습니다.)
- 이 액션은 **Safari 공유 시트에서 실행할 때만** 입력을 받습니다.
  단축어 앱에서 ▶︎로 직접 돌리면 입력이 없어 실패하는 게 정상입니다.

### ② 사전 가져오기 (Get Dictionary from Input)

- 입력: ①의 결과. JSON 문자열이 사전으로 바뀝니다.

### ③ 사전 값 가져오기 (Get Dictionary Value) — 키 `status`

### ④ 만약 (If) — `status` 가 `ok` 와 같음

**"그렇지 않으면" 쪽 (차단·미완성):**

1. 사전 값 가져오기 — 키 `reason`
2. **알림 표시 (Show Alert)**: `수집 중단 — [status] / [reason]`
3. **단축어 중단 (Stop Shortcut)**

> 이게 인수인계 문서 §8의 종료코드 2 정책(차단 → 즉시 중단·재시도 금지)입니다.
> **차단일 때는 파일을 만들지 않습니다.** 차단 페이지 텍스트가 CSV로 흘러드는 것을 막습니다.
> `empty`가 뜨면 페이지가 덜 뜬 것이니 잠깐 기다렸다 다시 실행하세요.

**"만약" 쪽 (정상):** 아래 ⑤부터 계속.

### ⑤ 메뉴에서 선택 (Choose from Menu) — "무엇을 담았나요?"

세 갈래를 만들고, 각 갈래에서 **변수 설정 (Set Variable)** `접미사` 에 아래 값을 넣습니다.

| 메뉴 항목 | `접미사` 값 | 언제 |
|---|---|---|
| 옵션 | *(빈 텍스트)* | 옵션을 펼친 상품 페이지 |
| 판매자 | `_sellers` | 다른 판매자 목록을 연 상태 |
| 검색 | `_search` | 검색 결과 페이지 |

> 기존 수동 경로의 `<상품키>_search.txt` 규칙을 그대로 잇습니다.

### ⑥ 사전 값 가져오기 — 키 `productId` → **변수 설정** `상품키`

> **PC의 `--from-text`가 상품명 기준 파일명을 기대한다면** 여기서 `사전 (Dictionary)` 액션으로
> `8868816986` → `그릭마일드` 같은 매핑 표를 만들고 `사전 값 가져오기`로 바꿔치기하세요.
> Python 코드를 안 고치고 규칙을 맞추는 방법입니다. (`../pc-side/NOTES.md` 참고)

### ⑦ 사전 값 가져오기 — 키 `text`

### ⑧ 파일 저장 (Save File)

- 파일: ⑦의 결과
- **저장할 위치 묻기: 끔**
- 서비스: iCloud Drive
- 대상 경로: `/coupang-price/manual/[상품키][접미사].txt`
- **파일이 이미 있으면 덮어쓰기: 켬** (같은 날 다시 담으면 최신값으로 갱신 — CSV 중복 판정과 같은 정책)

> 대상 경로에 파일명을 못 넣는 버전이면, `파일 저장` 전에 **이름 변경 (Rename File)** 액션으로
> `[상품키][접미사].txt` 를 지정하고 폴더만 대상으로 지정하세요.

### ⑨ (선택) 알림 표시 — `저장됨: [상품키][접미사].txt`

## 3. 조립 확인

단축어 앱에서 ▶︎로 돌리면 **①에서 실패하는 것이 정상**입니다(입력이 없음).
실제 확인은 Safari에서:

1. Safari로 `m.coupang.com/vm/products/8868816986` 열기
2. 공유 → `쿠팡 수집`
3. 알림이 뜨고 파일 앱 `iCloud Drive/coupang-price/manual/`에 `.txt`가 생기면 성공

처음 실행 시 "이 단축어가 웹페이지 내용에 접근하려고 합니다" 같은 권한 요청이 뜹니다. 허용하세요.
