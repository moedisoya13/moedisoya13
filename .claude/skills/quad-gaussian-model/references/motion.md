# 모션: 걷기 · 회전판 · 보조 뼈 구동

단계 ⑨. `template/motion.py`를 고치거나 새 동작을 지을 때 읽는다. 영상에서 동작을 가져오는 것은 `mocap.md`.

## 함수의 모양

- `*_rots(skel, phase, …)` → `(rots, root)`: 뼈별 로컬 회전 dict + root 이동. 한계 검사·보조 뼈 구동은 이 단계에서 한다.
- `*_pose(skel, phase, …)` → `(mats, root)`: 뼈별 3×4 행렬 + root. 렌더러(`Renderer.frame(cam, mats, root)`)가 받는 형태.
- `phase`는 0…1의 한 주기. **`pose(1) = pose(0)`** 이어야 loop다(`verify --checks loop`: `seam_position < 1e-5`).

새 동작을 짓는 순서: 관절 각도를 `rig.local_rot(뼈, pitch, yaw, roll)`로 채운 dict → `rig.check_limits(rots)`가 빈 목록인지 확인 →
`motion.drive_helpers(rots)`로 보조 뼈 채움 → `SKEL.world_mats(rots, root_offset=root)`.

## 걷기 loop — `motion.walk_pose(skel, phase, advance)`

`advance = STRIDE × phase`를 주면 실제로 전진하고, 0이면 제자리(러닝머신) 걷기다.

| 상수 | 값 | 뜻 |
|---|---|---|
| `STRIDE` | 0.64 H | 한 주기(두 걸음)에 발 하나가 가는 거리 |
| `STANCE` | 0.62 | 한 주기 중 발이 땅에 있는 비율 |
| `PITCH_STRIKE` / `PITCH_OFF` | −14° / 38° | 뒤꿈치 착지 때 / 발끝으로 밀 때의 발 기울기 |
| `SWING_LIFT` | 0.038 H | 뜬 발이 가장 높을 때의 추가 높이 |
| `MAX_REACH` | 0.995 | 다리가 펴지는 최대 비율(1 미만이라 IK가 발을 끌지 않음) |
| `ROOT_SWAY` | 0.012 H | 디딤발 쪽으로의 좌우 이동 |

"자연스럽게"를 만든 네 가지 — 순서가 중요하다. **발을 먼저 정하고 몸을 거기에 맞춘다.**

1. **발의 경로를 월드 좌표로 정한다.** 디딤발은 ① 뒤꿈치 한 점을 축으로 발바닥이 내려앉고(−14° → 0°) ② 발바닥 전체로 서 있다가 ③ 발가락 경첩을 축으로 뒤꿈치가 들린다(0° → 38°, 발가락 뼈는 바닥에 그대로). 세 구간 모두 축이 되는 점이 월드에서 고정이라 발이 미끄러질 수 없다. 발의 방향은 `rot_x(pitch)`만 쓰므로 돌 수 없다.
2. **뜬 발은 월드 속도 0에서 떠나 0으로 내려온다**(ease-in/out). 몸 속도로 날아와 갑자기 멈추지 않는다.
3. **골반 높이는 발에서 역산한다**(`root_height`): "두 다리가 길이의 99.5 %까지만 펴지고도 발목에 닿는 가장 높은 높이"를 부드럽게 이은 값. 걸음의 위아래 출렁임(약 0.041 = 실제 4 cm)이 저절로 나오고, 다리가 모자라 IK가 발을 끌어당기는 일이 생기지 않는다.
4. 무릎은 2-bone IK(`leg_ik`), 팔은 같은 쪽 다리와 반대로(어깨 −24°…+18°, 치마를 스치지 않게 9° 벌림), 가슴은 허리 회전판에서 골반과 반대로(±9°), 머리는 목 회전판에서 다시 정면.

통과 기준(`verify --checks feet`, `soldier.foot_report`): `stance_slide < 1e-4`(실측 5.1e−8), `stance_heading_deg < 1e-4`,
`max_reach < 1`, `limit_violations = 0`, 지면 오차 ±0.004 이내, `landing_speed`·`liftoff_speed` < `body_speed`의 2 %.

## 회전판 데모 — `motion.turn_pose(skel, phase, bend=0)`

제자리에서 허리 yaw = 40°·sin(2π·phase), 목 yaw = 70°·sin(2π·(phase + 0.30)). 위상이 엇갈려 허리와 목이 서로 다른 순간에 끝에 닿는다.
`bend`(도)를 주면 허리 앞뒤 굽힘이 더해져 원판 속 공이 드러난다. 회전판을 고쳤으면 이 클립을 반드시 본다.

## 보조 뼈 구동 — `motion.drive_helpers(rots, phase=0, walk=0, chest_spin=0, head_spin=0, prev=None, dt=1/24)`

걷기 위상을 몰라도 되는 **임의의 자세**용 함수다. `rots`의 pelvis·chest·head·thigh·shin·foot 회전만 읽고 보조 뼈 12개의 회전을 같은 dict에 채운다(약 0.4 ms).

| 보조 뼈 | 구동 | 잰 값 |
|---|---|---|
| 치마 8쪽 | 쪽마다 벨트 밑 경첩에서 **바깥쪽으로만**. 각도 = 그 쪽 아래의 넓적다리·무릎(다리를 따라 놓은 공 12개)이 천에 닿지 않는 최소 각도 | 넓적다리 40° → 앞왼쪽 18°, 80° → 53°, 100° → 85° (최대 125°). 다리 30° 벌림 → 옆쪽 17° |
| cape, capeTip | 가슴의 pitch·roll을 되돌려 수직으로 늘어뜨리고 yaw는 절반만 따라감. 엉덩이·치마 뒤쪽·다리 뒤를 지나도록 필요한 만큼 뒤로 기욺 | 가슴 25° 숙임 → 17°, 발꿈치를 엉덩이까지 차올림 → 33° |
| plume, plumeTip | 고개를 돌리면 반대로 휨 | 최대 ±25° |

- `walk`(0~1)·`phase`: 걸음에 맞춘 작은 흔들림(밑단 0.8°, 망토 6°, 깃털 끄덕임). **0이면 자세만으로 결정**되고, 쉬는 자세에서는 정확히 단위 회전이다.
- `chest_spin`·`head_spin`(도/주기, 주기 1초로 보면 도/초): 망토와 깃털이 도는 쪽에 뒤처진다.
- `prev`·`dt`(관성): 프레임마다 **같은 dict**를 넘기면(처음엔 `{}`) 들린 천이 곧바로 떨어지지 않고 초당 200°(치마)·120°(망토)로 내려온다. 넘기지 않으면 자세만의 함수라 loop가 그대로 loop다.

**부드러운 함수의 조건** — 구동 각도는 두 함수를 거친다.

- `soft_max`: 어느 공이 미는지 바뀌어도 각도가 꺾이지 않게 섞는다. 진짜 최댓값보다 아래로 내려가지 않는다(내려가면 천이 다리에 닿는다).
- `soft_pos(x, eps)`: 매끈한 `max(x, 0)`. **x ≤ 0에서 정확히 0, x ≥ eps에서 정확히 x**, 그 사이는 기울기가 0에서 1로 이어지는 곡선. 0 이하에서 0이 아닌 매끈한 함수를 썼을 때 천이 몸 쪽으로 들어간 적이 있다(테스트 `test_soft_pos_is_zero_below_zero_and_smooth`가 고정). 새 구동 함수도 이 두 조건(0 이하에서 정확히 0, 필요한 값에 못 미치지 않음)을 지킨다.

새 보조 뼈의 구동을 쓸 때의 틀: ① 그 천이 피해야 할 몸의 점들을 공으로 근사(`leg_points`) → ② 조각마다 "닿지 않으려면 필요한 각도" 계산(`gore_needs`, `cape_need`) →
③ 쉬는 자세의 필요량을 빼서 쉬는 자세가 0이 되게 → ④ `soft_pos`와 최대각으로 자름 → ⑤ `rig.rot_axis(경첩 축, 각도)`.

## 합성 달리기·도약 (옷 시험용)

`motion.run_pose`, `motion.jump_pose`, `motion.big_poses()`는 모션 캡처가 아니라 **관절 범위만 흉내 낸 합성 자세**다(발 접지 없음):
달리기는 넓적다리 앞 80°~뒤 20°·무릎 최대 123°, 도약은 웅크림 → 차오름 → 무릎을 가슴으로(넓적다리 100°, 무릎 125°) → 착지.
치마·망토·소매가 큰 동작에서 어떻게 되는지 재는 데 쓴다(`animate --clips big`, `verify --checks clash`의 run·jump·big 열).
발이 땅에 붙는 달리기·도약은 `synth.py`(합성 캡처)나 실제 모션 캡처 쪽에 있다.

## 알려진 한계

- 천은 휘지 않는다. 넓적다리를 100° 들면 그 위의 치마 쪽이 벨트에서 수평으로 뻗어 나온다.
- 뒤꿈치 착지 때 신발이 지면을 최대 1.7 mm(192px에서 0.15픽셀) 파고든다(둥근 뒤꿈치를 한 점 축으로 굴린 근사).
- 넓적다리를 뒤로 20° 뻗은 채 무릎을 125° 접으면 종아리가 뒤쪽 치마 밑단을 4.7 cm 파고든다(달리기에서는 그 조합이 나오지 않아 0).
