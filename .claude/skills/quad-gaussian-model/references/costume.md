# 복식: 이미지를 읽어 뼈별 층으로 옮기기

단계 ⓪(이미지 읽기)과 ⑤(복식 층)를 할 때 읽는다. 고치는 파일은 `costume.py` 하나가 중심이다.

## 목차
1. 이미지에서 무엇을 가져오나
2. 복식 표 쓰기
3. outfit의 약속 (`body.wear`가 기대하는 것)
4. 층 하나 만들기: 형태 → 칠
5. 겹침과 이음매
6. 재질
7. 늘어지는 것: 보조 뼈
8. 관통 검사에 올리기
9. 사진의 실루엣을 그대로 쓰기 (`photo/`)
10. 병사의 복식 표 (본보기)

## 1. 이미지에서 무엇을 가져오나

가져오는 것은 **복식 요소**다: 어떤 조각이 어디에 있고, 어떤 형태·색·재질·무늬이며, 무엇 위에 무엇이 얹히는가.
병사는 일러스트 2장에서 15세기 보병의 복식(샐릿 투구, 턱가리개, 어깨 판금, 두건 망토, 마름모 문양 겉옷, 부푼 소매,
두 색 타이츠)을 가져왔다. 얼굴·머리 모양·표정 같은 **그림 속 인물의 생김새는 가져오지 않고** 코·입·턱만 있는 일반형으로 둔다.
`costume.py` 머리말에 무엇을 참고했는지 한 줄로 적는다. 이미지 파일 자체는 저장소에 넣지 않는다.

몸의 비례는 기본적으로 이미지가 아니라 인체 비율 표(`rig.RATIO`)에서 온다. 일러스트는 비례를 과장하기 쉽고, 그림의 비례를
눈대중으로 옮기면 걷기와 관절 한계가 그 몸에 맞지 않게 된다. 과장된 체형이 목적이면 `rig.md` 9절로 체형부터 바꾸고 검증한 뒤 옷을 입힌다.

## 2. 복식 표 쓰기

이미지를 직접 열어(Read) 부위마다 한 행을 쓴다. 이 표가 사용자에게 확인받는 설계도이고 `costume.py`의 목차다.

| 열 | 적는 것 | 정하는 기준 |
|---|---|---|
| 부위 | 투구, 어깨 판금, 소매 … | 이미지에서 따로 읽히는 덩어리마다 |
| 붙는 뼈 | `head`, `clavL`, `upperarmL` … | 그 조각이 **무엇과 함께 움직이는가**. 턱가리개는 고개를 돌려도 안 따라가므로 `neck` |
| 층 이름 | `helmet`, `pauldron`, `sleeve` … | 칠할 때 구분할 단위. 색·재질이 다르면 층을 나눈다 |
| 형태 | 구 + 잘라낸 평면, 캡슐, 둥근 상자, 회전체, 살 + 두께 | `pixelsplat/sdf.py`의 기본 도형과 `body.round_box`, `body.disc` |
| 색 / 재질 | red / 천, steel / 판금 … | `MAT`의 이름으로 |
| 무늬 | 마름모, 줄무늬, 징, 단추 | 쉬는 자세 좌표의 어떤 함수인가 |
| 얹히는 순서 | "망토 위에 어깨 판금" | 두께를 더 크게 줄 쪽 |
| 움직임 | 강체 / 보조 뼈(무엇이 구동) | 관절을 넘거나 늘어지는가 |

이미지끼리 다르거나 가려져 안 보이는 부분(등, 겨드랑이, 발바닥)은 "추정"이라고 표에 적고 사용자에게 묻는다.
표의 모든 행에 붙는 뼈와 층 이름이 채워지면 ⓪ 완료다.

## 3. outfit의 약속

`body.py`는 옷을 모른다. `body.wear(outfit)`에 넘기는 모듈(또는 객체)이 아래를 갖추면 된다.

| 이름 | 무엇 |
|---|---|
| `BONES` | 옷만이 입체를 주는 보조 뼈 목록(치마 쪽, 망토, 깃털) |
| `layers(bone, p)` | `{층 이름: 거리 (N,)}` — 그 뼈의 입체에 합쳐질 층들. 옷이 없는 뼈는 `{}` |
| `paint(bone, p, layer)` | `(albedo (N,3) sRGB, roughness (N,), metallic (N,))`. `layer` = 점마다 가장 가까운 층의 이름 |
| `box(bone)` | 옷 입은 뼈 입체의 쉬는 자세 상자, 또는 `None`(맨몸 상자 그대로) |
| `LIMITS` (선택) | 입는 동안 좁아지는 관절 한계 |
| `VOXEL_SCALE` (선택) | 뼈별 조형 격자 배율(1보다 작으면 촘촘) — 얇은 천·작은 장식이 있는 뼈 |

`soldier.py`의 `OUTFITS = {"none": None, "soldier": costume}`에 등록된 이름이 `--outfit`의 선택지다.
옷을 한 벌 더 만들려면 `costume.py`를 복사해 새 모듈로 두고 `OUTFITS`에 추가한다.

치수는 키 1.80 기준 값으로 쓰고 `S = rig.H / 1.80`을 곱한다(`m(v)` = 길이, `pt(x, y, z)` = 점). 키를 바꿔도 옷이 따라온다.

## 4. 층 하나 만들기: 형태 → 칠

어깨 판금(뼈 `clav`)의 코드가 전형이다(실제 `costume._clav`·`_paint_clav`를 줄인 것).

```python
def _clav(p, s):                                   # s = +1 왼쪽, -1 오른쪽
    sh = rig.SHOULDER[s]
    flesh = body.BUILDERS["clav" + ("L" if s > 0 else "R")](p)[body.FLESH]   # 이 뼈의 맨몸
    q = p - P(sh)
    cap = np.maximum(sdf.length(q) - PAULDRON_R, -(q @ n) - m(0.010))         # 공을 평면으로 자른 반구 덮개
    return {"mantle": flesh - MANTLE_T * 0.9,       # 살을 두께만큼 부풀린 천
            "pauldron": cap, "strap": strap, "buckle": buckle}

def _paint_clav(p, layer, s):
    pa = Paint(len(p), "yellow")                    # 바탕 재질
    plate = layer == "pauldron"
    pa.set(plate, "steel")
    pa.set(plate & (h < m(0.004)), "steel_dark")    # 말린 테두리: 좌표의 조건으로 칠한다
    pa.set(plate & 리벳_조건, "gold")
    return pa.out()
```

자주 쓰는 형태:

| 만들고 싶은 것 | 방법 |
|---|---|
| 몸에 붙는 천 | `flesh - 두께` (맨몸 SDF를 부풀림). 한쪽만 두껍게 하려면 두께에 좌표의 `clip(…)`을 곱한다 |
| 판금·투구 | 구·타원체를 평면으로 잘라(`np.maximum(a, 평면)`) 껍질로. 가장자리는 `steel_dark`로 칠해 두께를 읽히게 |
| 부푼 소매·주름 | 타원체를 `sdf.smin`으로 살에 녹여 붙임. 주름은 형태가 아니라 칠의 밝기 변화(`pa.shade(0.93 + 0.07·cos(각·9))`)로 |
| 띠·끈 | `sdf.capsule`, 줄무늬는 띠를 따라간 길이의 `tri()` |
| 리벳·벨트 징 | 작은 것은 형태가 아니라 칠의 조건으로(각도를 N등분해 `|t − round(t)| < 폭`) |
| 단추·버클·브로치 | 조금 큰 것은 작은 구·둥근 상자를 따로 층으로(`buttons`, `buckle`) |
| 얇은 천(망토·치마 쪽) | 가운데 면까지의 거리 `|z − mid(x, y)| − 반두께`를 옆·위·아래 평면으로 자른 껍질. 세로 주름은 `mid`에 cos을 더한다 |
| 톱니 밑단 | 밑단 높이를 좌표의 삼각파 `tri(x / 폭)`로 흔들어 자른다 |

같은 뼈 안의 층은 합집합(min)으로 합쳐지므로, 옷이 살을 덮으면 살의 그 면은 메시에 나오지 않는다. 병사는 맨몸 표면적의
43 %가 옷 층에 덮여 사라졌다. 층을 살보다 얇게(음수 두께로) 만들면 살이 뚫고 나오니, 옷은 늘 살 바깥에 둔다.

**칠만으로 끝나는 옷**: 타이츠, 신발 몸통, 얼굴처럼 형태가 맨몸과 같은 것은 층을 만들지 않고 `paint`에서 색만 바꾼다
(`layers`가 `{}`를 돌려주는 뼈). 구슬도 그 자리 옷 색으로 칠한다(무릎 = 타이츠, 팔꿈치 = 소매, 허리 원판 = 벨트).

조형 후 "solid of bone … touches its box"가 나오면 그 뼈의 기본 이름(`clav`처럼 L/R 없이)을 `_DRESSED`(옷 입은 뼈 목록)에 넣어
`box()`가 옷 입은 입체에서 상자를 다시 재게 한다. 재는 범위는 뼈 축에서 0.42까지다(`body.measure_box`의 `reach`) — 창·큰 날개처럼
그보다 멀리 뻗는 조각은 `reach`를 늘리거나 보조 뼈를 따로 준다(코드에서 읽은 것, 겪어 본 것은 아님).

## 5. 겹침과 이음매

- **관절을 넘는 옷은 나눈다.** 소매 = 위팔 조각 + 아래팔 조각. 어깨 판금 = 쇄골의 덮개 + 위팔의 판 두 겹 — 팔을 들면 위팔의 판이 덮개 밑으로 미끄러져 들어간다.
- **이음매는 부모 쪽이 덮는다.** 구슬은 자식 뼈에 붙으므로 미끄러지는 선은 부모 쪽 소켓 가장자리다. 그 위를 부모 쪽 옷자락(끝동, 판금 덮개, 치마 윗단)이 지나가게 하면 이음매가 옷 속으로 들어간다.
- **위에 얹히는 것이 더 두껍다.** 망토 위의 어깨 판금처럼 얹히는 조각은 설계상 아래 조각 속에 파묻혀 있다(병사: 0.037). 관통 표에서 이 쌍은 "쉬는 자세 대비 얼마나 더 들어가는가"로 본다.
- **회전판 위**: 허리 원판 높이에서 가슴 쪽 옷은 원판 반지름 안에 있어야 돌 때 윤곽이 변하지 않는다. 턱가리개처럼 고개를 돌려도 가만히 있는 것은 목(부모)에 붙이고 안쪽 반지름을 턱이 도는 반지름보다 크게 잡는다(병사: 0.110 > 0.093).
- **옷이 관절을 막으면 한계를 줄인다.** 투구 꼬리가 망토에 닿는 각도를 `verify --checks clash`로 재고, 닿지 않는 범위를 `costume.LIMITS`에 적는다.

## 6. 재질

`MAT = {이름: (albedo sRGB, roughness, metallic)}`.

| 재질 | roughness | metallic | 메모 |
|---|---|---|---|
| 천 | 0.85~0.88 | 0 | |
| 가죽 | 0.50~0.55 | 0 | |
| 강철 | 0.36 | **0.55** | 완전한 금속(1.0)은 어두운 스튜디오 배경을 비춰 검게 보인다. 밝은 청회색으로 읽히게 낮춘다 |
| 금 장식 | 0.32 | 0.65 | |
| 보석 | 0.15 | 0 | |
| 살 | 0.60 | 0 | |

금속·가죽·천을 섞어 써야 specular 하이라이트가 화면을 살린다. 꼭짓점마다 다른 roughness·metallic은 작은 경사 텍스처의
좌표로 실려 간다(`soldier.ATLAS`) — 코어의 메시 part가 값을 하나만 갖기 때문이며, 새 재질을 넣어도 손댈 것은 없다.

`--paint rig`는 옷을 회색으로, 구슬을 황동색으로, 회전판을 청색으로 칠해 구조만 보여 준다. 형태를 잡는 동안 쓸 만하다.

## 7. 늘어지는 것: 보조 뼈

천을 시뮬레이션하지 않는다. 강체 조각을 **몸의 자세에서 계산한 각도**로 돌린다(`motion.drive_helpers`, 자세한 것은 `motion.md`).

| 조각 | 구조 | 구동 |
|---|---|---|
| 치마 | 골반에 고정된 윗단 + 벨트 밑 경첩에 매달린 **8쪽**(45°씩, 이웃과 0.5° 겹침) | 쪽마다 바깥으로만 젖힘. 각도 = 그 아래 넓적다리·무릎이 천에 닿지 않는 최소 각도 |
| 망토 | 가슴에 2마디(cape, capeTip) | 가슴의 숙임·기울임을 되돌려 수직으로 늘어뜨리고, 엉덩이·치마·다리 뒤를 지나도록 필요한 만큼 뒤로 기욺 |
| 깃털 | 머리에 2마디 | 고개를 돌리면 반대로 휨 |

새 보조 뼈를 넣는 순서: ① `rig.py`에 뼈의 머리·꼬리 점과 `make_skeleton()`의 한 줄 → ② `costume.BONES`와 `layers`·`paint`에 그 뼈의 조각 →
③ `motion.drive_helpers`에 구동 → ④ `costume.COVERS`/`THROUGH`에 관통 검사 → ⑤ sculpt·bake 다시.
조각 수의 교훈: 치마를 4장으로 나눴을 때 옆판이 앞판을 뚫었다. 8쪽으로 늘리고 각자 **자기 방향 바깥으로만** 젖히게 하자 이웃을 뚫을 수 없게 됐다.
대가로 쪽마다 젖혀진 각도가 다르면 사이가 벌어져 속(타이츠·치마 윗단)이 보인다 — 그래서 치마 속 골반도 타이츠 색으로 칠해 두었다.

## 8. 관통 검사에 올리기

`verify --checks clash`는 `costume.py`의 선언만 본다. 새 조각을 넣고 여기에 안 올리면 뚫려도 숫자에 안 나온다.

- `CLASH_PAIRS`: `(이름, 그룹 A, 그룹 B)`. 그룹 = `[(뼈, 층 목록 또는 None = 뼈 전체, 점 마스크 또는 None), …]`. A의 보이는 표면이 B 입체 속으로 들어간 최대 깊이를 잰다.
- `THROUGH`: `(이름, 옷 뼈들, 그 밑의 뼈들)` — 밑에 있어야 할 것이 옷의 **바깥면 밖으로** 나온 거리. 양수면 화면에 보인다.
- `COVERS[옷 뼈]`: 점이 그 옷을 얼마나 뚫고 나왔는지 돌려주는 함수(`gore_poke`, `cape_poke`).

읽는 법: 두 입체는 속이 찬 덩어리라 깊이가 양수여도 들어간 표면은 상대 속에 숨고 **만나는 선만** 보인다. 눈에 띄는 것은
`THROUGH`의 양수다. 병사 실측: 넓적다리·무릎이 치마를 뚫고 나옴 — 걷기 −0.022, 달리기 −0.022, 도약 −0.020(전부 안쪽),
한계인 고관절 120°에서 +0.002.

## 9. 사진의 실루엣을 그대로 쓰기 (`photo/`)

날개·방패·깃발처럼 **윤곽이 형태의 전부인 얇은 판**은 사진에서 오려 SDF로 쓸 수 있다. 니케의 좌우 날개가 이렇게 만들어졌다.
`photo/extract_wings.py`와 `photo/wings.py`는 그 실제 코드로, 사진과 결과 파일(`wings.npz`)은 들어 있지 않다. 숫자(픽셀 좌표·문턱값)는
그 사진 두 장에 맞춘 것이라 **그대로 돌리는 도구가 아니라 고쳐 쓰는 본보기**다.

1. **분리**: 밝기 또는 채도 문턱으로 대상을 배경에서 떼고, 손으로 그린 다각형(`keep`) 안만 남긴다. 다각형의 경계가 몸통과 만나는 곳이 뿌리 절단선이 된다(`segment`).
2. **정합**: 같은 사진에 보이는 몸의 기준점 두 개(니케: 목 절단면 y = 0.64, 발바닥 y = −1)로 축척과 높이를 맞추고, 카메라는 옆에서 `elev`도 아래에서 `dist`만큼 떨어져 본다고 둔다. 카메라 위치는 사진에 기록이 없어 **추정**이다(몇 도 차이로 끝이 몇 백분의 1 단위 움직인다).
3. **옮기기**: 판 위의 점 (z, y)마다 그 점이 투영되는 사진 픽셀을 찾아 실루엣 마스크와 결(relief)을 모델의 옆 평면에 그린다. 판이 끝으로 갈수록 몸에서 멀어지는 것(`sheet_x`)을 반영하므로 "아래에서 올려다본" 치우침도 함께 풀린다.
4. **입체화**: 실루엣의 2D 부호 거리(`sdf`)를 판 `x = sheet_x(z, y)` 둘레의 두께로 돌출한다. 앞 가장자리·뿌리는 두껍게, 끝은 얇게, 결을 양면에 눌러 넣는다(`wings.py`).
5. **결**: 어두운 사진은 밝기에서 높이를 얻기 어렵지만 결의 **방향**은 믿을 만하다 → 밝기의 structure tensor로 방향을 구하고 그 방향으로 노이즈를 문질러(LIC) 능선과 골을 만든다(`feather_relief`).

이렇게 만든 판을 인물에 붙일 때는 뼈 하나의 층으로 넣거나(강체), 보조 뼈를 주어 움직인다. 사진 원본은 저장소에 넣지 않고
파생 결과(작은 `npz`)와 출처만 남긴다. 사진 라벨을 믿지 말고 열어서 시점을 확인한다(분류명과 실제 시점이 달랐던 적이 있다).
