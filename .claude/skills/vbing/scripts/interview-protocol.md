# 하이브리드 인터뷰 프로토콜

사용자 서술에서 채워진 슬롯은 **질문 금지**. 비어 있는 슬롯만 `AskUserQuestion`으로 묻는다.

## 슬롯 정의

| # | 슬롯 | 질문 예시 | 선택지 |
|---|---|---|---|
| 1 | **목적** | "이 데이터로 무엇을 보여주고 싶으세요?" | 비교 / 관계·상관 / 분포 / 구성비 / 추이 |
| 2 | **데이터 소스** | "데이터는 어디서 오나요?" | CSV/Excel 파일 / 대화로 값 입력 / 이미 로드된 DataFrame |
| 3 | **주요 변수** | "x축과 y축에 어떤 컬럼을 쓰나요? 그룹이 있나요?" | 자유서술 (컬럼명) |
| 4 | **강조** | "강조하거나 표시할 부분이 있나요?" | 없음 / 최대값 / 평균선 / 이상치 / 특정 구간 |
| 5 | **스타일** | "스타일 선호가 있나요?" | 기본 / 다크 테마 / seaborn whitegrid / 프레젠테이션용 큰 폰트 |

## 파싱 규칙

서술에서 다음 패턴이 감지되면 해당 슬롯을 **자동 채움**:

- **목적**: "비교", "vs", "차이" → 비교 / "관계", "상관", "어떻게 영향" → 관계 / "분포", "몇 개", "얼마나" → 분포 / "비율", "%", "구성" → 구성 / "변화", "시간", "추이", "트렌드" → 추이
- **데이터 소스**: `.csv`·`.xlsx`·`.json` 확장자 감지 / `[...]`·`{...}` 인라인 값 감지
- **변수**: 컬럼명 인용부호 또는 따옴표 / "x축은 ~", "y축은 ~"
- **강조**: "최대", "최소", "평균", "이상치", "강조"
- **스타일**: "다크", "프레젠테이션", "논문용", "깔끔"

## 질문 최소화 원칙

- 모든 슬롯 채워짐 → 질문 0회, 바로 코드 생성
- 1~2 슬롯 비어 있음 → `AskUserQuestion` 1회 호출에 묶어서 질의
- 3 슬롯 이상 비어 있음 → 우선순위 상위 2개만 질의 (목적 → 변수 → 데이터 소스 순)

## AskUserQuestion 호출 템플릿

```
questions: [
  {
    question: "어떤 목적의 차트를 만들까요?",
    header: "Purpose",
    options: [
      {label: "카테고리 비교", description: "막대그래프로 크기 비교"},
      {label: "두 변수 관계", description: "산점도로 상관관계 확인"},
      {label: "값의 분포", description: "히스토그램/박스플롯"},
      {label: "시간 추이", description: "선그래프로 변화 추적"}
    ]
  }
]
```

## 예시 플로우

**사용자**: "sales.csv에서 월별 매출 막대그래프, 최대값 강조"

파싱 결과:
- 목적 = 비교 (감지: "막대그래프")
- 소스 = CSV (감지: `.csv`)
- 변수 = x:월, y:매출
- 강조 = 최대값 (감지)
- 스타일 = 기본

→ **질문 0회**, 즉시 `templates/comparison.py::bar_with_max` 로딩하여 코드 출력.
