# 땡큐 피치 — 3구 승부 (Three.js 시네마틱)

만화 **『땡큐 피치』(サンキューピッチ, 스미요시 큐)** 1부의 줄거리를 Three.js로 만든
**62초 자동 재생 시네마틱**입니다. 밤의 요코하마 소하고 그라운드에서 벌어지는
「야구부 사냥꾼」의 3구 승부와, 그 뒤에 있는 사연·스카우트까지를 8개 챕터로 압축했습니다.

## 실행

가장 간단한 방법 — 빌드 산출물을 그냥 엽니다.

```
thankyou-pitch/dist/index.html   ← 더블클릭 (인터넷 연결 불필요)
```

three.js까지 전부 인라인된 단일 HTML 파일이라 서버도 CDN도 필요 없습니다.

소스에서 돌리려면:

```bash
cd thankyou-pitch
npm install
npm run dev      # 개발 서버
npm run build          # dist/index.html 재생성
npm run verify         # Playwright 검증 (콘솔 에러 + 챕터별 스냅샷)
npm run build:artifact # 문서 스켈레톤 안에 넣을 페이지 조각으로 변환
```

`build:artifact`는 빌드 결과에서 `<title>`·`<style>`·본문 마크업·인라인 스크립트를 뽑아
`<!doctype html><head>…</head><body>` 스켈레톤 안에 삽입할 수 있는 조각을 만듭니다.
호스팅 페이지나 iframe에 그대로 끼워 넣을 때 씁니다.

## 조작

컨트롤 바는 평소 흐려져 있다가 마우스를 움직이면 나타납니다.

| 키 | 동작 |
|---|---|
| `Space` / `K` | 재생 · 일시정지 |
| `←` `→` | 5초 뒤로 · 앞으로 |
| `1` ~ `8` | 챕터 점프 |
| `R` | 처음부터 |
| `C` | 자막 켜기/끄기 |
| `M` | 사운드 켜기/끄기 |

사운드는 브라우저 자동재생 정책 때문에 **기본 음소거**입니다. 컨트롤 바의 「사운드」를
누르면 켜집니다. 외부 오디오 파일 없이 WebAudio로 전부 합성합니다 — 수은등 점등음,
공이 공기를 가르는 소리, 미트 포구음, 배트 헛스윙, 관중 웅성임, 그리고 긴장도에 따라
필터와 킥이 열리는 앰비언트 패드.

## 8챕터 구성

| # | 구간 | 장면 |
|---|---|---|
| 1 | 0–7s | **소문** — 달빛만 있는 빈 그라운드. "6월, 가나가와." |
| 2 | 7–14s | **야구부 사냥꾼** — 조명탑이 하나씩 점등되며 마운드 위 실루엣이 드러난다 |
| 3 | 14–21s | **미끼** — 주장 코보리 헤이타가 스스로 타석에 들어선다 |
| 4 | 21–29s | **1구 — 스트레이트** 163 km/h. 배트는 나오지도 못한다 |
| 5 | 29–37s | **2구 — 나이아가라 포크** 같은 궤도에서 절벽처럼 떨어진다. 헛스윙 |
| 6 | 37–46s | **3구 — 문 임팩트** 배트 위를 스쳐 떠오른다. 삼진 |
| 7 | 46–54s | **정체** — 입스. 전력으로 던질 수 있는 공은 하루 세 개뿐 |
| 8 | 54–62s | **스카우트** — "그 3구, 우리 팀에 빌려줘." → 타이틀 |

HUD 우상단의 **「던질 수 있는 공」 3개 표시**가 구를 던질 때마다 하나씩 꺼집니다.
이 작품의 제약이 곧 이야기라서 가장 크게 보이도록 뒀습니다.

## 구조

```
src/
  main.js           부트스트랩, 렌더 루프, 리사이즈/가시성/정리
  story.js          ★ 8챕터 대본 (시간·자막·카메라·연출·사운드 큐)
  director.js       타임라인 재생 / 일시정지 / 시크
  pitches.js        3구의 궤적 (순수 함수)
  layout.js         필드 좌표계 상수
  cameraRig.js      샷 보간, 흔들림, 세로 화면 화각 보정
  scene/
    world.js        렌더러 + 포스트프로세싱(Bloom·비네트·그레인)
    stadium.js      그라운드·조명탑·백네트·관중석·전광판·밤하늘
    players.js      로우폴리 인물 리그와 포즈 키프레임
    ball.js         공·트레일·임팩트
  ui/               자막 · HUD · 컨트롤 바 · 플래시/타이틀
  audio/            WebAudio 엔진 · 효과음 · 앰비언트 음악
tools/verify.mjs    Playwright 검증 스크립트
```

### 설계 원칙: 화면은 시간의 순수 함수

`chapter.apply(t)`가 시각 `t`의 화면 상태를 **통째로** 다시 만듭니다. 프레임 간에
누적되는 상태(감쇠 스무딩, 파티클 잔상 등)를 쓰지 않기 때문에 타임라인을 아무 데로나
스크럽해도 같은 프레임이 나옵니다. 공 트레일도 지난 프레임을 쌓는 대신 궤적 함수를
거꾸로 샘플링해서 그립니다. 되돌릴 수 없는 것(사운드)만 `cues[]`로 분리해서, 디렉터가
전진 재생 중 큐를 지날 때만 발사합니다.

### 에셋이 없는 이유

이 프로젝트는 외부 네트워크가 막힌 환경에서 만들어졌습니다. GLTF 모델도, 오디오 파일도,
웹폰트도 받을 수 없어서 **전부 코드로 생성**합니다 — 인물은 캡슐/박스 리그, 잔디·흙·야구공
실밥·백네트·전광판은 canvas 2D 텍스처, 소리는 오실레이터와 노이즈, 3D 안의 한글은
`CanvasTexture`. 덕분에 결과물이 단일 HTML 파일 하나로 떨어집니다.
