# 룩(look) 옵션: 레퍼런스 화질에 다가가기

> 목표: Tommaso Checchi의 "Almost Pixel Perfect" 기사(knight) 샘플과 우리 니케 렌더의 **차이를 재고, 그 차이를 줄이는 옵션**을 넣는다.
> 모든 옵션은 **기본값이 꺼짐**이라 기존 코드(`render_frame`, `shade`, `postprocess` …)의 결과는 그대로다.
> 켠 묶음은 `pixelsplat.shade.stylized()` · `clean_frame()`, 니케 전용 조합은 `examples/nike/look.py`에 있다.

## 1. 레퍼런스와 무엇이 달랐나 (측정값 포함)

레퍼런스 이미지를 아트 픽셀¹ 단위로 되돌려(188×303, 화면 4px = 아트 1px) 통계를 냈다.

| 항목 | 레퍼런스 | 이전 니케 (128px) | 의미 |
|---|---|---|---|
| 밝기 중앙값 / 하위 5% / 상위 1% (sRGB) | 0.32 / 0.03 / 0.93 | 0.53 / 0.22 / 0.84 | 레퍼런스는 **어두운 바탕에 일부만 밝다**(low-key). 우리는 전체가 밝고 그림자가 회색 |
| 채도 평균 | 0.32 | 0.11 | 우리는 거의 무채색 대리석 |
| 색상 분포 | 주황·노랑 + 보라 그림자 | 회청색 한 덩어리 | 밝은 곳은 따뜻하게, 어두운 곳은 차갑게(색상 이동²) |
| 이웃 픽셀 밝기차 평균 | 0.039 (중앙값 0) | 0.075 | 레퍼런스는 **같은 색 픽셀이 2~4개씩 뭉친 "붓자국"**. 우리는 픽셀마다 다른 splat이 찍혀 자글자글 |
| 하이라이트 | 작고 선명한 흰 점 + 주변 번짐(bloom³) | 없음 | |
| 외곽선 | 없음. 대신 뒤에서 오는 빛(rim)이 가장자리를 밝힘 | 어두운 외곽선 | 어두운 배경에서 어두운 외곽선은 실루엣만 깎는다 |
| 배경 | 남색 + 모델 주변이 아주 살짝 밝음 | 단색 | |
| 해상도 | 캐릭터 키 ≈ 290 아트 픽셀 | ≈ 120 | 레퍼런스가 2.4배 촘촘하다 |

## 2. 옵션

### G-buffer 정리 (`FrameConfig`, 모듈 `pixelsplat/gbuffer.py`)
혼합 없는(hard) 합성은 픽셀마다 splat **하나**만 보인다. splat이 픽셀보다 작으면 어느 것이 뽑힐지가 거의 우연이라 점 노이즈(speckle)가 생긴다.

| 옵션 | 하는 일 |
|---|---|
| `supersample=2` + `select` | G-buffer를 2배 크게 그린 뒤 아트 픽셀마다 **투표**: 절반 이상이 덮였는지(실루엣 — 4표 중 2표 동점은 덮인 것으로 본다. 그래야 아트 픽셀 경계에 걸친 가는 선이 사라지지 않는다), 과반이 보는 깊이 층(어느 면인지)을 정하고, 그 층의 표본만 평균(`"mean"`, 기본) 하거나 가장 대표적인 표본 하나를 고른다(`"medoid"`⁴). 다른 면과는 절대 섞지 않으므로 가장자리는 그대로 칼같다. patch snap 이동량은 아트 격자 기준으로 정한 뒤 배율만 곱한다 |
| `despeckle=True` | 이웃 8칸 대부분과 같은 면인데 혼자만 법선·색이 다른 픽셀, 뒤가 비쳐 보이는 구멍(pin-hole)을 같은 면의 대표 이웃으로 교체. 1픽셀 폭의 선은 서로를 지지하므로 남는다 |
| `normal_smooth=0.6` | 법선만 부드럽게. 깊이가 다르거나 방향이 많이 다른 이웃은 제외해서 주름·경계는 유지 |

`clean_frame(shade)` = 위 세 가지를 켠 `FrameConfig`(hard + snap).

### 조명·색 (`ShadeConfig`)
| 옵션 | 하는 일 |
|---|---|
| `terminator` | 밝은 면은 경계 직전까지 밝게 두고 명암 경계⁵에서 빠르게 떨어뜨림(2단 램프를 Lambert에 섞음) |
| `ssao`, `ssao_radius` | 화면 공간 ambient occlusion: 주름 속·깃털 사이를 어둡게 |
| `cavity`, `ridge` | 법선의 곡률로 골은 어둡게, 능선은 밝게 → 형태가 선으로 읽힘 |
| `rim`, `rim_power` | 모델 뒤쪽 조명이 가장자리를 스치는 빛 |
| `spec_scale` | 직접광 specular 세기 |
| `outline_silhouette`, `outline_tint` | 배경과 닿는 외곽선만 따로 세기 지정(0이면 안쪽 깊이 경계에만 선) |
| `contrast`, `saturation`, `shadow_tint`, `highlight_tint`, `tint_strength` | 색 보정: 밝기 S커브(색상 유지), 어두운 곳·밝은 곳의 색 기울이기 |
| `bloom`, `glow` | 하이라이트 번짐 / 배경에 모델 색의 옅은 후광 |
| `palette_colors` + `fit_palette()` | 클립 전체에서 **한 번** 뽑은 고정 팔레트(프레임마다 k-means를 돌리는 기존 `palette`는 색이 깜빡임) |
| `flat_splats` | 같은 splat이 찍힌 픽셀을 한 색으로(splat이 픽셀보다 클 때 "붓자국") |

`stylized(base)` = 위 옵션을 조정된 값으로 켠 복사본. `low_key=True`(기본)는 노출·주변광도 낮춘다.

### splat LOD (`pixelsplat/lod.py`, 실험적)
`merge_splats` / `lod_for_camera`: 아트 픽셀보다 작은 splat을 3D 격자 칸 + 법선 방향별로 합쳐 큰 splat 하나로 만든다(위치·법선·재질은 면적 가중 평균).
128px에서 60k → 약 1.3만 개, **래스터가 약 4배 빨라진다**(같은 픽셀 수 기준 실측). 화질 지표는 합치지 않은 모델 + G-buffer 정리와 비슷한 수준이어서 기본 룩에는 넣지 않았다(빠른 미리보기용).

### 대리석 칠 (`examples/nike/marble.py`)
형태(SDF)만 보고 칠하므로 조형이 바뀌어도 그대로 동작한다. 층: 크림색 바탕 → 꿀색·황토색 patina⁶(가려지고 낮은 곳일수록 진함) → 오목한 곳의 때 → 골의 어두운 선(음의 곡률) → 능선 마모(양의 곡률) → 빗물 자국 → 미세한 색 흔들림과 결.
`paint(..., detail=1.0)`의 `detail`은 미세한 층의 세기다(작은 스프라이트는 낮게). `style="flat"`은 이전 칠.
`examples/nike/repaint.py`는 **이미 학습한 모델을 다시 칠한다**(조형·학습 없이 약 1분).

## 3. 측정 (60k 모델, 128px, Almost Pixel Perfect)

정지 프레임(걷기 3/28 프레임):

| | 밝기 중앙/하위5%/상위1% | 채도 평균 | 이웃 밝기차 평균 |
|---|---|---|---|
| 이전 | 0.53 / 0.22 / 0.84 | 0.11 | 0.076 |
| 렌더러만 개선 | 0.51 / 0.11 / 0.82 | 0.20 | 0.073 |
| + 새 칠 | 0.52 / 0.10 / 0.81 | 0.26 | 0.089 |
| 레퍼런스 | 0.32 / 0.03 / 0.93 | 0.32 | 0.039 |

움직임 (`scripts/look_stability.py`, 자세 고정, 카메라를 프레임당 0.13px 이동(pan) / 0.15° 회전(orbit), 9프레임).
`changed` = 색이 바뀐 물체 픽셀 비율, `mean |Δ|` = 바뀐 양의 평균(0~255), `flicker` = 튀었다가 다음 프레임에 돌아온 픽셀.

| 모델 | 설정 | pan changed / mean \|Δ\| | orbit changed / mean \|Δ\| |
|---|---|---|---|
| 60k, 이전 칠 | 이전 (hard + snap) | 12.9% / 3.96 | 6.2% / 1.58 |
| | + G-buffer 정리 | 14.5% / 3.70 | 7.8% / 1.52 |
| | + stylized | 16.5% / 4.13 | 9.6% / 1.81 |
| 60k, 새 칠 | 이전 (hard + snap) | 14.2% / 4.64 | 6.9% / 1.94 |
| | + G-buffer 정리 | 17.0% / 4.36 | 11.3% / 2.02 |
| | + stylized | 18.7% / 5.08 | 13.7% / 2.59 |

flicker는 모든 행에서 0.1% 미만이다. 걷는 8프레임(실제 움직임 포함)에서는 flicker가 1.02% → 0.87%.

**정직한 요약**: G-buffer 정리는 정지 화면의 점 노이즈·구멍을 없애고 걷기 중 깜빡임을 조금 줄이지만,
카메라가 서브픽셀로 흐를 때 **"바뀐 픽셀 수"는 1.6~4.4%p 늘어난다.** snap만 켠 원본은 patch 내부가 완전히 고정되는데,
여러 표본의 평균과 이웃을 참고하는 정리 단계는 값이 조금씩 연속으로 변하고 patch 이음새도 넘나들기 때문이다.
바뀐 **양**(`mean |Δ|`)은 pan에서 6~7% 줄고 orbit에서는 비슷하다(−4% ~ +4%). 대비·질감을 올린 stylized와 새 칠은 그만큼 변화량도 키운다.
가만히 흐르는 카메라에서 최대한 고정된 픽셀이 필요하면 `supersample=1`(정리 끔)이 여전히 가장 안정적이다.

## 4. 아직 모자란 점
- **붓자국 느낌**: 레퍼런스는 quad가 픽셀보다 커서 같은 색 픽셀이 뭉친다. 우리는 128px에서 splat이 픽셀과 비슷하거나 작아 픽셀마다 값이 다르다. LOD로 splat을 키우는 길은 열어 두었지만 아직 레퍼런스만큼 차분하지 않다.
- **재질 다양성**: 레퍼런스는 금속·가죽·천이 섞여 specular 하이라이트가 화면을 살린다. 대리석 한 재질로는 밝은 점이 적다.
- **해상도**: 같은 화면 크기에서 레퍼런스가 아트 픽셀이 2.4배 많다. 256px로 렌더하면 격차가 크게 준다.

---
¹ **아트 픽셀**: 확대하기 전, 저해상도 그림의 픽셀 한 칸.
² **색상 이동(hue shifting)**: 픽셀아트에서 그림자를 단순히 어둡게만 하지 않고 색을 차갑게(보라·파랑), 밝은 곳은 따뜻하게(노랑) 옮기는 관습.
³ **bloom**: 아주 밝은 부분의 빛이 주변으로 번져 보이는 효과.
⁴ **medoid**: 여러 표본 중 "나머지와 가장 닮은" 실제 표본 하나. 평균과 달리 값을 섞지 않는다.
⁵ **명암 경계(terminator)**: 빛을 받는 면과 그림자 면이 만나는 선.
⁶ **patina**: 오래된 돌·금속 표면에 생기는 따뜻한 색의 풍화층.
